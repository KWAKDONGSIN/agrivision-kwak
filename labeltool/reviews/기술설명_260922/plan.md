# 계획 — 라벨링 툴 기술설명 PDF · 깃 반영 · 팀원 편집 권한

사용자 요청(12:24) 세 가지.
1. «사이트에서 데이터 수정을 하면 바로 저장되는가» 에 답한다(실측으로).
2. «정확히 어떤 기술로 어떻게 만들었는지» 설명하는 PDF 를 만들고 사용자 깃(agrivision-kwak)에 올린다.
3. 팀원들도 이 사이트(툴)를 수정할 수 있게 한다.

가정(사용자에게 물어보지 않고 고른 기본값).
- «수정할 수 있도록» = 툴 **코드**를 팀원이 고칠 수 있게. 서버 폴더는 이미 lab 그룹 쓰기 가능이므로 부족한 것은 «파이썬 고친 뒤 서버 다시 켜기»(kds0206 프로세스라 팀원이 못 끔) 와 «깃 push 권한»(깃허브 협업자 추가는 사용자만 가능) 둘이다.
  → 감시자(watchdog)가 `logs/restart.flag` 를 보면 다시 켜게 한 줄 더한다. 깃허브 협업자 추가는 사용자에게 순서를 알려 준다.
- PDF 는 A4 `pdfdoc.py` 로. md 원문도 같이 둔다(수정은 md 에서, PDF 는 재생성).
- 공개 저장소에 PDF 를 넣는다(A1 에서 «사람용 PDF 사본은 안 올린다» 로 정리했지만 이번은 사용자가 직접 «깃에 옮겨줘» 라 함 → 이 한 부만 예외로 올리고 NOT_UPLOADED/README 에 적는다).
