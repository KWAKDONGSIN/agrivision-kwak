### 2-2. 레이어 칸 줄이기 + 중복 스위치 숨기기 — ✅ (문구 한 곳 ❌ → 고침)

- `#box-mode`·`#num-mode` 는 DOM 에 남아 있고 화면에서만 숨었습니다(`modesim` 31/31 · `boxsim` 50/50 그대로).
- **`.dupsw{display:none!important}` 의 접근성**: `display:none` 이라 탭 순서에서도 빠집니다 → **키보드 덫(보이지 않는데 포커스가 가는 칸)은 없습니다.** 이건 `visibility:hidden` 이나 `opacity:0` 보다 나은 선택입니다.
  다만 화면 낭독기(스크린리더)에도 안 읽히므로 «상자 모드를 켜는 길» 은 ② 단추와 `X` 키뿐입니다 — ② 단추가 `<button>` 이고 `X` 가 살아 있으니 기능 손실은 없습니다.
- ❌ **`<summary>` 가 거짓말을 했습니다**: «더 보기 — 번호 색·**필름**» 인데 «필름 진하기» 는 그 `<details>` **밖에** 있습니다(② 상자 그리기에서만 보이는 줄). 펴 봐도 없습니다. → **고쳤습니다**(§8).

## 5. 코드 리뷰 (시킨 네 가지)

### 5-1. `ui.js` 의 문턱표 `TH` — «데이터가 바뀌면 낡는» 문제
- 구조는 받아들일 만합니다. 사진 한 장만 보는 화면에서 «그 과일의 하위 20%» 를 실시간으로 알 길이 없고, `server.py` 를 못 고치는 이번 사이클에서는 다른 수가 없습니다.
- 진짜 위험은 «낡는 것» 자체가 아니라 **낡은 줄 아무도 모른다**는 점입니다. 값이 언제 것인지, 몇 장으로 잰 것인지가 코드 주석에만 있습니다.
- `TH_DEFAULT = {dice:0.75, added:0.01}` 는 **새 과일이 들어오면 옛 문턱으로 돌아갑니다** — 그 과일에서 경고가 다시 80% 가 될 수 있는데 아무 경고도 안 뜹니다. 최소한 «이 과일은 문턱을 아직 안 쟀습니다» 를 회색으로 한 줄 다는 편이 정직합니다.
- **`splitFlags` 는 견고합니다** — `;` 와 `|` 둘 다 받고 공백을 털고 빈 것을 버립니다. `inspection.csv` 가 어느 쪽 구분자를 쓰든 안전합니다(실측: 사과 `merged_blob`·`fg_too_low`·`single_convex_blob` 모두 바르게 갈렸습니다).

### 5-2. prompt 가드 (`ensureWho`)
- **N1 가드와 충돌하지 않습니다.** 안내 창 가드가 `window` capture 에 **먼저** 등록되고 `stopImmediatePropagation()` 을 쓰므로, **같은 `window` 에 나중에 붙은 `ensureWho` 리스너까지 함께 멈춥니다.** (`stopPropagation` 이었다면 안 멈췄을 것입니다 — 우연이 아니라 맞는 선택입니다.) 실측으로도 확인했습니다.
- `askedWho = true` 를 **`#who` 값을 보기 전에** 켭니다 → 이름이 이미 있으면 묻지 않고, 없으면 딱 한 번 묻습니다. 취소해도 다시 안 묻습니다. 의도대로입니다.
- **새로고침 뒤에도 안 묻습니다 — 코드로 확인했습니다.** `app.js:928` 이 `$("#who").value = localStorage.getItem("who") || ""` 로 되돌려 놓고, `ensureWho` 는 그 값이 있으면 곧바로 `return` 합니다. `app.js:929` 의 `onchange` 는 사람이 직접 고칠 때용이고, prompt 로 받은 이름은 `ensureWho` 가 자기가 `localStorage` 에 씁니다 — **양쪽이 겹치지 않고 빠지지도 않습니다.**
- 남는 흠 하나(고치지 않았습니다): 키 가드가 `"1234".indexOf(e.key) >= 0` 이라 **번호 편집 모드에서 숫자키를 쓰는 날이 오면** 이름을 묻게 됩니다. 지금은 안 씁니다.
- `prompt()` 라는 선택 자체: 브라우저 기본 창이라 못 꾸미지만 **«일을 막지 않는다»**(취소해도 진행)는 성질이 중요하고 실제로 그렇게 동작합니다. 초보자에게는 이 편이 «저장 버튼이 안 눌리는» 것보다 낫습니다. 저는 찬성합니다.

1. **M1 수정(§8-1)이 «2차가 손대도 되는 명백한 버그» 범위였는가.** 저는 «화면이 상태와 반대말을 한다» 는 점에서 사이클 1 의 N3·N9 와 같은 종류로 봤습니다.

6. **M7(`TH` 가 낡는 문제)** — 지금은 «`TH_ASOF` 주석 2줄» 로 넘기고, 백분위를 서버가 계산하는 일은 사이클 3 의 `server.py` 수정과 묶을 것인가.
