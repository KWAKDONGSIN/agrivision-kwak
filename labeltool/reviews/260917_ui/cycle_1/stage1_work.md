### 왜 `ui.js` 를 따로 뒀나 (설계 판단)

`app.js` 의 `setNumMode` · `numKey` · `setTool` · `$("#box-mode").onchange` · `keydown` 은 회귀 시험
`cycles/260917_신기능/cycle_2/stage2/modesim.js` 가, 상자 함수들은 `.../stage1_client/boxsim.js` 가
**소스에서 글자 그대로 잘라 내** node 에서 돌립니다. 그 함수 안에 새 함수 호출(`syncTaskUI()`)을 넣으면
가짜 DOM 환경에 그 함수가 없어 시험이 `ReferenceError` 로 깨집니다. **시험을 고쳐서 통과시키지 않기 위해**
`ui.js` 는 기존 함수를 가로채지 않고 **200ms 마다 상태를 읽어 화면만 맞춥니다**(서명이 같으면 DOM 미접촉).
그래서 `app.js` 수정은 `renderCounts()` 한 군데(진행률 막대)뿐입니다.

### 기존 것을 하나도 안 깨뜨렸다는 근거

- **요소 id**: 새로 추가만 했고 기존 id(`#box-mode` `#num-mode` `#l-*` `#btn-*` `#boxpanel` `#numpanel` `#f-*` …)는 이름·의미 그대로.
- **단축키**: `app.js` 의 `keydown` 을 손대지 않았습니다. `ui.js` 는 **별도 리스너**로 `?` 와 `Esc`(안내 창)만 추가.
- **API·저장 형식**: 새 엔드포인트 0개. 빠른 필터는 기존 `select/checkbox` 를 대신 눌러 주고 `loadList()` 를 부를 뿐.
- **상태 공유**: ② 단추 = `#box-mode` 체크박스 = `X` 키, ③ 단추 = `#num-mode` = `K` 키. 셋이 같은 상태 하나를 씁니다.
  «`X` 로 꺼도 ② 단추의 불이 따라 꺼진다» 를 **네 과일 모두 브라우저로 실측**(§5).

## 6. 고친 «깨진 배치» 두 가지 (원인까지)

1. **목록 카드가 38px 로 찌그러져 파일 이름·딱지가 안 보였다** (지시서에 없던, 브라우저로 처음 발견한 문제)
   원인: `.grid` 가 `flex: 1 1 auto` 인 flex 아이템이면서 암시적 행이 `auto` 라, 행이 남은 높이에 맞춰 눌렸습니다
   (`align-content: start` 로는 막지 못함). 카드 안의 `img`(108px)는 `overflow:hidden` 에 잘려 있었습니다.
   측정: 고치기 전 카드 높이 **38.3px**(img 108px) → `grid-auto-rows: max-content` 한 줄로 **150.4px**, 실서버에서 **165px**.
2. **«상자 모드» 줄이 세 칸으로 깨져 보였다** (`~/ff_shots/selfcheck_apple.png` 에서 보이던 것)
   원인: `.lay` 가 `flex-wrap: nowrap` 인데 한 줄에 «체크박스 + 색칠 + 굵은 글씨 + 설명 + 괄호 설명» 5개가 들어가 있었음.
   고침: 설명을 `.hint` 로 줄 밖으로 빼고 `.lay { flex-wrap: wrap }`. 같은 이유로 긴 레이어 이름을 짧게
   («알마다 다른 색 (인스턴스 라벨)» → «알마다 다른 색 (I)», «열매 번호 (번호마다 색, J)» → «열매 번호 (J)»).

## 7. 가정 (물어보지 않고 정한 것)

1. **판정·저장 칸은 세 작업 어디에서나 보입니다.** 지시의 «고른 작업의 패널·도구만 보이고 나머지는 숨김» 은
   *작업별* 칸(도구 / 상자 / 번호)에만 적용했습니다. 판정(`1`~`4`)은 «이 사진을 쓸 것인가» 라 작업과 무관하고,
   단축키 `1~4` 는 어느 모드에서나 살아 있으므로 화면에서 숨기면 오히려 «키는 먹는데 단추는 없는» 상태가 됩니다.
2. **«도구» `<details>` 는 기본 «펼침»** 으로 뒀습니다. 한 장 검수의 가장 흔한 길이 «보고 `1` 누르기» 라 해도,
   접어 두면 처음 온 사람이 붓을 못 찾습니다. 대신 `요약`에 «붓으로 고칠 때만 펴세요» 를 적었습니다.
3. **첫 방문 안내는 `localStorage['tour_seen_260917_ui1']`** 에만 기록합니다(브라우저별·사람별).
   서버·`data/` 에 아무것도 쓰지 않습니다. «다시 보지 않기» 는 기본 체크입니다.
4. **화면 갱신 주기 200ms.** 즉시성이 필요한 곳(3칸 단추 클릭)은 클릭 직후 `tick()` 을 직접 부르므로 지연이 없고,
   `X`·`K` 키로 바꿨을 때만 최대 200ms 늦게 단추 불이 따라옵니다(실측에서는 사람이 못 느끼는 수준).
5. **범례 줄은 1400px 이하에서 숨깁니다**(자리를 다 먹어서). 빠른 필터 단추는 계속 보입니다.
6. 목록 카드 범례에서 «아직 안 봄» 은 회색 테두리라 흐리게 보입니다 — 원래 카드 색과 맞춘 것이므로 그대로 뒀습니다.
7. 위 제목을 «과일 마스크 검수·수정 툴» → «과일 라벨 검수 툴» 로 줄였습니다(`<title>` 태그는 그대로).
   이제 마스크만 다루는 툴이 아니기 때문입니다.
