## ④ 사이클 2 가 할 일 (확정 · 우선순위순)
1. **N2 — 판정 단추를 어느 창에서도 보이게.** 방식 확정: 판정 5단추를 **사진 아래 가로 한 줄**(캔버스 영역 하단에 고정, 단추 안 설명은 한 줄 유지·좁으면 풍선말로)로 옮기고, 메모 칸과 «수정본 되돌리기» 는 그 줄 오른쪽 또는 옆 패널에 둔다. id 는 그대로(`#btn-ok` 등). 합격 기준: 1366×768·1280×720·1920×1080 에서 5/5 가 화면 안, 캔버스 높이는 창의 55% 이상.
2. **레이어 칸 줄이기** — 기본 3줄(원본 라벨·AI 제안·내 수정본) + 투명도, 나머지는 `<details> 더 보기`. **«상자 모드 (X)»·«번호 편집 모드 (K)» 체크박스는 화면에서 숨김**(②·③ 단추와 같은 스위치라 중복) — 요소는 DOM 에 남겨 `modesim.js`·`boxsim.js` 가 그대로 통과해야 함.
3. **N4 «이 사진에서 할 일» 문턱** — 어떤 경고도 그 과일 사진의 **25% 를 넘게 뜨지 않게**. 사과의 `merged_blob`·`filled_blob`(833장, 표시 문제로 판정됨)은 경고에서 제외하고 «알마다 다른 색(I)으로 보세요» 안내로 대체. `0.0%` 값은 문구에 넣지 않음. 과일별 발동 비율을 실측 표로 보고.
4. N5 딱지 범례 항상 표시 · N6 검색 칸 300ms 디바운스 + 자리표시자 · N7 판정된 사진에도 의심·Dice 를 회색으로 · N8 «번호 오류» 빠른 단추는 오류 목록이 있는 과일에서만 · N9 저장 뒤 «할 일» 줄이 상태와 같은 말을 하게(`app.js:746` 근처 한 줄 허용) · 범례의 «초록 = 내 수정본» 은 실제로 고친 것이 있을 때만.
5. «내 이름» 이 비어 있으면 **첫 판정·저장 때 한 번** 물어본다(«익명» 기록 방지). `<title>` 을 화면 제목 «과일 라벨 검수 툴» 과 맞춘다.

## ⑤ 사이클 3 으로 넘기는 것 — 녹취 «일일이 우리가 할 수는 없으니까»
- **중복 묶음을 한 번에**: 묶음 사진을 열면 묶음 구성원 썸네일 줄 + **어느 장이 대표인지** 표시 + «대표만 남기고 나머지 제외» 한 단추(확인창 + 되돌리기). 지금은 5장 묶음에 `4` 를 네 번 눌러야 함.
- **의심 종류별 빠른 단추**(«속이 찬 동그라미» `filled_blob`·`single_convex_blob` 등) — 교수님이 짚은 사과 문제를 바로 모아 보기.
- **카운팅 답이 화면에**: 진행 현황에 과일별 «열매 번호 총 개수»(사과·블루베리), 사진 카드에 «N개». 서버 집계는 캐시.
- 2차 §10 중 **기각 2건**: (가) «번호에 AI 초벌 단추가 없다» → 번호 패널의 «처음 번호로» 가 초벌 다시 부르기입니다(문구만 «처음 번호(초벌)로 다시» 로 다듬기). (나) «누가 몇 장 했나 가 없다» → 진행 현황 탭에 «검수자별» 표가 이미 있습니다(README §5). 다만 목록 화면에서 안 보이는 것은 사실이므로 진행률 옆에 «내가 한 장수» 만 추가 검토.
