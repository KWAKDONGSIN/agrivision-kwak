### 2-2. 고침 (백업 `app/_backup_260918_ui9_server.py`)

`server.py` 에 함수 하나를 더해 두 곳(`action=="fixed"`·`action=="ai"`)이 같은 문장을 쓰게 했습니다. **+28줄.**

```python
def _save_verdict(fruit, stem, by, note):
    """마스크를 저장했을 때 판정을 어떻게 적을지 — 한 곳에서 정한다(0918 UI사이클5 N-C)."""
    with lock_for("status:" + fruit):
        before = read_status(fruit).get(stem) or {}
    if before.get("status") != "exclude":
        return update_status(fruit, stem, "fixed", by, note, keep_prev=True), False
    old = str(before.get("note") or "")
    # 메모 칸은 이 사진의 메모로 **미리 채워져** 있다(app.js) → 사람이 새로 적었을 때만 이어 붙인다
    new_note = (old + " · (수정본 저장) " + note)[:300] \
        if (note and not old.startswith(note.strip())) else old
    st = update_status(fruit, stem, "exclude", by, new_note, keep_prev=True)
    return st, True
```

- **규칙**: `exclude` 는 «이 사진을 쓸지» 에 대한 판정이라 그림을 고친 것으로 풀리지 않는다(번호 저장과 **같은 규칙**).
  `flag` 는 지금처럼 `fixed` 로 **풀린다**(사람이 실제로 고쳤으므로) — `prev` 에 사유·좌표가 보관됩니다.
- **메모는 원래 것을 앞에 그대로 둡니다.** 일괄 제외 되돌리기가 «`중복: ` 으로 시작하는가» 를 보고 판단하므로
  앞부분이 바뀌면 안 됩니다. 사람이 메모를 새로 적으면 **뒤에** 이어 붙입니다.
- `keep_prev=True` 를 그대로 두었습니다 — 그래야 그 뒤의 «수정본 되돌리기» 가 돌아갈 자리(`prev`)를 압니다.
- **응답 칸은 `kept_exclude` 하나만 늘었습니다.** 기존 칸(`ok·status·wrote_mask·fg_pixels`)·저장 형식·단축키·요소 id 불변.
- 화면(`app.js` +10줄): 저장은 되고 **안내 창**이 뜹니다 —
  «그림은 저장했습니다. 다만 이 사진의 판정은 «제외» 그대로입니다 … 다시 쓰려면 «1 원본 그대로 OK» 를 누르거나 다른 판정으로 바꿔 주세요.»

## ⑯ 2차 검수자(Opus 5)가 봐 주었으면 하는 것

1. **N-C 의 규칙 판단**: «제외는 마스크 저장이 뒤집지 않는다» 가 맞는가. 그리고 **메모를 앞에 그대로 두는 방식**이
   일괄 제외 되돌리기(`note.startswith("중복: ")`)·내보내기 기록과 충돌하지 않는지 — 제 시험은 «앞부분이 안 바뀐다» 만 봤습니다.
2. **②③ 에서 메모 칸·«수정본 되돌리기» 를 숨긴 판단.** 캔버스 55% 를 지키려고 고른 것인데,
   «③ 번호 작업 중에 메모를 적고 싶다» 가 실제로 있을 수 있습니다. 다른 안: 메모 칸을 판정 줄 밖(옆 패널 맨 위)으로.
3. **범례 기본 접힘.** 처음 온 사람이 색 뜻을 못 보고 지나갈 위험 vs 왼쪽 위 붓질. 안내 4단계·사용법에 적었지만 충분한지.
4. **N-L·N-M 을 이번에 고칠지.** 둘 다 한 줄이지만 작업 목록 밖이라 손대지 않았습니다.
5. **`_save_verdict` 가 `before` 를 자물쇠 밖에서 읽는 것**(C3·코드 지적과 같은 계열). 동시성 260요청에서 문제는 없었지만
   «읽고 나서 쓴다» 는 구조 자체를 `update_status` 안으로 합치는 것이 깔끔한지.
6. **문턱표 `TH` 가 낡았습니다**(C2·M7) — 오늘 사과 제외가 454→572 로 늘었으므로 `thresholds.py` 를 다시 돌릴 때가 된 것 아닌지.
