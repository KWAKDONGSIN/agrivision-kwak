## 1. M1 — «✨ 초벌» 을 다시 구현하지 않고 «있는 것» 으로 바꿨다

### 1-1. 무엇이 문제였나 (사이클3 2차 §11 1순위)

번호가 없는 과일(복숭아·포도)에서 툴은 **이진 마스크를 4-연결로 세어** 상자를 만들었다.
같은 일을 검출 팀이 이미 워터셰드로 해 두었는데, **툴 쪽이 더 나빴다**:

| 복숭아 개수 | MAE | 출처 |
|---|---:|---|
| 툴이 마스크를 4-연결로 센 값 | **0.70** | 사이클3 2차 §5-4 |
| 박성문 님 워터셰드 | **0.30** | 같은 곳 · 이번 사이클이 재현(§2-2) |

### 1-2. 고친 것 — 규칙을 `instances.py` 한 군데에

```python
SEED_DIRS = {"blueberry": PARK + "/bbox_outputs/blueberry/all/instance_maps",
             "peach":     PARK + "/bbox_outputs/peach/all/instance_maps",      # ← 새로
             "grape":     DUP.DATA_DIR + "/grape/instances_seed"}              # ← 새로 (CERTH 정답 송이)
SEED_SOURCE = {"blueberry": "team:박성문", "peach": "team:박성문", "grape": "certh_gt"}
KIND_SOURCE = {"fixed": "human_fixed", "gt": "gt_numbers"}
CC4 = "cc4"
```

- **사과는 일부러 넣지 않았다.** `source_of()` 의 우선순위가 `fixed > seed > gt` 이므로,
  사과를 `SEED_DIRS` 에 넣으면 **워터셰드가 원본 정답 번호를 덮는다.** 사과는 원본 마스크에
  정답 번호가 들어 있으므로 그대로 `gt` 갈래를 쓴다.
- 새 함수 둘: `seed_source_of(fruit, stem)`(파일 있음만 보고 이름을 돌려준다 — 배열을 읽지 않는다) ·
  `source_name(fruit, kind)`(`load_inst()` 의 kind → 같은 낱말).
- 화면이 지어내지 않게 **서버가 이름을 준다**: `GET /api/boxes_seed` 응답에 `seed_source`,
  `GET /api/item` 의 `counts` 에 `seed_source`. 옛 이름 `source` 는 **그대로 남겼다**(호환).
