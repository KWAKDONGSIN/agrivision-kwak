## 4. 지표 표 검토

### 4-1. 식이 farjon 과 같은가 — **손계산 3장으로 확인(일치)**

복숭아 실제 세 장(`t1-07` 14/12 · `t1-10` 25/24 · `t1-11` 11/10)만 담은 표를 만들어 돌리고,
같은 값을 손으로 계산했다.

| | 손계산 | `count_metrics.py` |
|---|---|---|
| e = y−ŷ | 2 · 1 · 1 | |
| MAE = Σ\|e\|/n | 4/3 = **1.3333** | **1.33** |
| RMSE = √(Σe²/n) | √2 = **1.41421** | **1.41** |
| ȳ · Σ(y−ȳ)² | 16.6667 · 108.6667 | |
| R² = 1−Σe²/Σ(y−ȳ)² | 1−6/108.6667 = **0.944785** | **0.945** |
| 총량편향 = Σŷ/Σy−1 | 46/50−1 = **−8.00%** | **−8.00** |

→ `farjon2023countingreview` p.16 식 (1)~(4) 와 **같다**. 표본이 없거나 정답이 전부 같으면
R² 를 `—`(nan)로 두는 것도 맞다(자체 점검 5건이 그 갈래를 시험한다).

### 4-2. 🔴 «⚠순환» 이 **맞는 줄에만** 붙나 — **아니었다. 고쳤다.**

1차 판은 «오차가 정확히 0 이고 n≥2» 이면 무조건 «⚠순환» 을 붙이고 표 아래에
«센 값과 정답이 **같은 파일**에서 나왔습니다» 라고 **단정**했다. 반례를 실제로 만들어 확인했다:

- 사람이 확정한 개수가 **두 장 다 맞은** 표를 넣으면 «🟢 사람 확정 개수 **⚠순환**» 이 붙고
  «같은 파일에서 나왔다» 는 **거짓 설명**이 달렸다(`handcalc/loopcheck_peach`).
- 이것은 가짜 상황이 아니다 — **내 모래상자 실측 표**에도 그대로 나왔다:
  브라우저 회귀가 사람 확정 두 장을 만들자 «복숭아 / 🟢 사람 확정 개수 · n=2 · MAE 0.00» 이 생겼다.

**고친 뒤**: «알려진 순환 짝»(사과 `n_instances` · 포도 `n_instances`)에만 **⚠순환**,
나머지 오차 0 줄에는 **⚠오차0** 을 붙이고 «① 순환일 수도 ② 정말 다 맞은 것일 수도 있으니
`gt_source`·`human_source`(또는 `boxes_source`)로 확인하라» 고 적는다.
네 과일 실제 표는 **한 글자도 달라지지 않았다**(사과·포도 번호 줄에 ⚠순환 그대로).

### 4-3. 포도 R² **−1.406** 은 어떻게 읽나

R² = 1 − Σe²/Σ(y−ȳ)² 이므로 **음수 = «사진마다 다 같은 값(평균 3.9송이)이라고 답하는 것보다 나쁘다»**
는 뜻이다. 포도 자동 상자는 합계를 **+54.35%** 부풀리고(9,424 → 14,546) 장당 오차가 2.43송이다.
→ 표에 «포도 자동 계수는 쓸 수 없다» 는 말을 **그대로 실어야 한다**. 포도를 끈 지금은
«열매 번호» 줄이 없으므로 표에 남는 포도 숫자는 **자동 상자뿐**이고, 더욱 그렇게 읽힌다.

### 4-4. 블루베리 빠짐 문구 — **사실이다**

`park_seongmoon/bbox_outputs/` 를 직접 봤다: 사과·복숭아·포도에는 `gt_boxes/csv/detections.csv` 가
있고 **블루베리에는 `all` 뿐**이다. 표 아래 문장(«블루베리는 정답 상자 파일이 없어 이 표에 나오지
않습니다»)은 맞고, 뺀 줄 수 **1,114 = 블루베리 counts.csv 줄 수와 정확히 같다**.

### 4-5. ⚠ 표를 읽을 때 조심할 것 **두 가지**(1차 설명에 빠졌다)

1. **복숭아·블루베리에서 «열매 번호» 줄과 «박성문 자동 상자» 줄은 같은 값이다** —
   125장 **전부**에서 `n_instances == n_team_park`(실측). M1 이 툴 초벌을 박성문 워터셰드로
   바꿨으니 당연하지만, 표에서는 **세 줄(번호·박성문·임성후)이 같은 숫자**로 나란히 보여
   «세 방법이 일치한다» 로 오해하기 쉽다. **한 번의 측정이 세 줄로 보이는 것**이다.
   (사과·포도는 다르다 — 사과 330장 / 포도 1,857장에서 번호와 팀원 상자 값이 다르다.)
2. **사과 표는 1,001장이 아니라 429장이다**(툴이 근접중복 대표만 들고 있다). 정답 합계도
   40,468 이 아니라 **17,567** 이다. 논문 표에 쓸 때 «사과 429장(대표 1장 기준)» 을 밝혀야 한다.

### 4-6. 통합 `v3` 로 돌리면 왜 비나 — **사이클 5 재빌드 지시에 넣을 문장**
