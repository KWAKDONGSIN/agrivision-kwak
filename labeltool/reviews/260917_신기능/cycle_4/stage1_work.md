## ③ 속도 수정과 «결과가 같다» 는 증거

### ③-1 무엇을 고쳤나 (`app/boxes.py`)

판정서 ④ 가 준 코드 그대로, 루프를 **모듈 최상위 순수 함수**로 뺐습니다(자체 점검이 실제 함수를 시험할 수 있게):

```python
def boxes_of(lab, min_px=4, limit=MAX_BOXES):
    lab = np.asarray(lab).astype(np.int32)
    cnt = np.bincount(lab.ravel())             # 번호마다 화소 수 — 4화소 규칙을 한 번에
    out = []
    for i, s in enumerate(ndimage.find_objects(lab), start=1):
        if s is None or cnt[i] < min_px:
            continue
        ys, xs = np.nonzero(lab[s] == i)       # 슬라이스 안에서만 본다
        out.append({"id": len(out) + 1, "cls": "fruit", "src": "auto",
                    "xyxy": [int(s[1].start + xs.min()), int(s[0].start + ys.min()),
                             int(s[1].start + xs.max()) + 1, int(s[0].start + ys.max()) + 1]})
        if len(out) >= limit:
            break
    return out
```
`api_boxes_seed` 는 루프 12줄이 `boxes = boxes_of(lab)` 한 줄로 바뀌었습니다.
지킨 것 📄: (a) 번호 **오름차순** — `find_objects` 는 1..max 순이라 `np.unique` 와 같은 순서 (b) 4화소 규칙은 `bincount` 로 동일 (c) `MAX_BOXES` 상한 유지 (d) 조각난 번호는 슬라이스가 조각 전체를 덮음.
판정 지시대로 **단추 잠금은 넣지 않았습니다**(yagni). `boxes.py:126 source` 파라미터에 판정서가 준 ponytail 한 줄만 붙였습니다(삭제 안 함 — 복숭아·포도가 씁니다).
`demo()` 에 **5×5 장난감 배열** 자체 점검을 넣었습니다(번호 1·2 각 4화소 + **3화소 번호 3 → 빠짐** + **두 조각 번호 4 → 상자 하나가 조각 전체**) + 번호 0개 + `limit` 상한.

📄 줄 수: `app/boxes.py` **225 → 252 (+27)** — 함수 본체 + 왜 그렇게 하는지 설명 + `demo()` assert 4줄. 성능 수정이라 ponytail 범위 밖이고 줄이 늘었습니다(판정서 ⑦ «깎을 것 없음» 그대로).
