## ③ 초벌 수정과 네 과일 대조표

### ③-1 무엇을 고쳤나 (`app/boxes.py:api_boxes_seed`)

📄 고치기 전: `lab = labeled(fruit, stem, "ai" if source=="ai" else "gt")` — **늘 이진 마스크의 연결성분**. 화면이 `S.ai ? "ai" : "gt"` 를 보내고 네 과일 4,823장 전부 AI 제안이 있으므로 **항상 AI 제안의 연결성분**이었습니다.

📄 고친 뒤 (핵심 6줄):

```python
p, kind = INST.source_of(fruit, stem)
if p:
    lab, source = INST.read_u16(p), "instances:" + kind
else:
    source = "ai" if source == "ai" else "gt"
    lab = labeled(fruit, stem, source)
```

- 번호를 **어디서 읽을지는 `instances.py:source_of` 한 군데**에 그대로 맡겼습니다(사람이 고친 것 `fixed` > 검출팀 초벌 `seed` > 원본 번호 `gt`). 규칙을 두 벌로 만들지 않으려는 것입니다(사이클 2 가 합쳐 둔 것을 지킴).
- 상자를 만드는 루프는 **건드리지 않았습니다**(판정서 «지금 루프 그대로»). 그래서 «4화소 미만 버림» 규칙도 그대로입니다.
- 번호가 없는 과일은 `source_of` 가 `(None, None)` 을 주므로 **예전 경로 그대로**입니다. 📄 복숭아·포도 20장에서 확인(③-2).
- 화면(`app/static/app.js:seedBoxes`)은 `S.inst ? "inst" : (S.ai ? "ai" : "gt")` 를 보내고, **응답의 `source` 를 그대로** 사람 말로 바꿔 보여 줍니다(`SEEDKO`). 즉 화면 안내가 «무엇을 보고 만들었나» 를 숨기지 않습니다.

❌ 판단: `source` 파라미터에 «이진으로 강제» 하는 값은 **넣지 않았습니다.** 쓰는 곳이 없고(YAGNI), 필요해지면 그때 한 줄입니다.

### ③-3 🔴 이번에 수치로 드러난 것 — 포도 초벌은 «개수» 가 아닙니다

📄 포도 10장에서 정답 51송이 ↔ 초벌 109개. 한 장 평균 절대오차 **6.4개**이고 `1439` 는 1송이를 **17개**로 셌습니다. 방향도 일정하지 않습니다(합쳐져 줄기도 하고 쪼개져 늘기도 함).

❌ 판단: 이것은 **고칠 버그가 아니라 라벨의 성질**입니다. 포도 마스크는 송이 «영역» 이고 잎이 앞을 가로지르면 한 송이가 여러 조각이 됩니다. 연결성분으로는 원리적으로 셀 수 없습니다. 그래서 README 에 «포도·복숭아 초벌은 세어 주는 것이 아니라 시작점» 이라고 **명시**했습니다(④-7). 진짜로 포도를 세려면 포도도 사과·블루베리처럼 **번호 마스크(인스턴스)가 있어야** 하고, 검출 팀 YOLO 라벨이 이미 2,502장 전량 있으니 그것을 초벌로 끌어오는 길이 있습니다 → **사람 결정거리로 ⑦ 에 올렸습니다**(사이클 4 내보내기 주제와 맞닿음).
