- 잠금을 안 넣는 이유 ❌: 고친 뒤 요청 한 번은 PNG 읽기 0.02 + 상자 0.07 + 전송 ≈ 0.2초 안이라 «두 번 누르는» 창이 사실상 없습니다. 📄 2차 실측대로 두 번 눌러도 결과는 같고 되돌리기 스택에 2칸이 쌓일 뿐 그림이 틀리지 않습니다. 0.2초 동작에 진행 플래그를 두는 것은 yagni. 사람 체크리스트에 «빠르게 두 번 눌러 보기» 한 줄을 넣어 눈으로 확인하고(⑨), 문제가 보이면 그때 1줄입니다.

**사이클 4 · 1차가 고칠 것** — `app/boxes.py:136-147` 루프를 **모듈 최상위 순수 함수**로 빼고 `api_boxes_seed` 는 그것을 부릅니다(자체 점검이 실제 함수를 시험할 수 있게 — 사이클 2 (나) 갈래가 `clean()` 에 한 것과 같은 꼴):

```python
from scipy import ndimage          # server.py 가 이미 scipy 를 씀

def boxes_of(lab, min_px=4, limit=MAX_BOXES):
    """번호마다 상자 하나 — 한 번만 훑는다(find_objects). 번호 오름차순, min_px 미만 번호는 뺀다."""
    lab = lab.astype(np.int32)                 # read_u16 은 uint32, labeled() 는 int32
    cnt = np.bincount(lab.ravel())
    out = []
    for i, s in enumerate(ndimage.find_objects(lab), start=1):
        if s is None or cnt[i] < min_px:
            continue
        ys, xs = np.nonzero(lab[s] == i)
        out.append({"id": len(out) + 1, "cls": "fruit", "src": "auto",
                    "xyxy": [int(s[1].start + xs.min()), int(s[0].start + ys.min()),
                             int(s[1].start + xs.max()) + 1, int(s[0].start + ys.max()) + 1]})
        if len(out) >= limit:
            break
    return out
```
