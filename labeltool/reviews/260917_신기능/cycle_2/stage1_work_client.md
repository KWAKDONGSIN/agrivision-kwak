### ⑴ D3 — 살아 있는 서버의 **실제 응답**으로 확인 (재시작 없이 curl 만)

📄 `peach/210629-t4-17`(1248×1664, 앞 갈래가 빈 목록으로 돌려 둔 시험용 stem)에 **정상 3개 + 2픽셀 미만 2개 = 5개** POST:

```
POST /api/boxes  HTTP 200  264 bytes
  {at: 2026-09-17 14:50:01, dropped: 2, n_boxes: 3, ok: true, over: 0}  boxes 길이 3
  boxes: [{id:1,cls:fruit,src:human,xyxy:[100,200,300,400]},
          {id:2,cls:bunch,src:human,xyxy:[10,10,60,80]},
          {id:3,cls:fruit,src:human,xyxy:[650,850,700,900]}]   ← 뒤집어 보낸 것이 정렬됨
GET  /api/boxes  HTTP 200 →  저장응답 boxes == 되읽기 boxes : True
```

이 **실제 응답 파일**을 `saveBoxes()` 에 먹인 결과(📄 `boxsim.js` §4):

| 확인 | 결과 |
|---|---|
| 보낸 5개 → 화면 | **3개** (3차 판정 ③ 이 요구한 검사) |
| `S.bDirty` | **false** |
| `S.bsel` | **-1** |
| `S.bundo.length` | **1** (버린 것이 있으므로) |
| 화면 목록 == 응답 | **글자까지 같음** · `id` 가 1,2,3 으로 다시 붙음 |
| 안내 글 | `상자 3개 (과실·알 2, 송이 1) · 저장됨 2026-09-17 14:50:01 · 너무 작아 버린 것 2 — 화면에서도 지웠음(Ctrl+Z 로 되돌려 볼 수 있음)` |
| flash | `상자 3개 저장 · 버린 것 2개` (**경고색**) |
| Ctrl+Z | **5개로 복원** → 무엇이 사라졌는지 볼 수 있음 |

📄 **3,005개 POST**: `{n_boxes: 3000, dropped: 0, over: 5}` + `boxes` 3,000개(**196,454 바이트**) → 화면도 3,000개로 줄고 되돌리기 1칸, 초과도 경고색. (서버 갈래의 «191KB» 실측과 일치)
📄 **예전 서버 방어**: `boxes` 가 `undefined`·`null`·`"그런거없음"`·`42`·`{0:"x"}` 인 5가지에서 **덮어쓰지 않고** `bDirty=false` 만.
📄 **저장 중 사진 바꿈**: 응답 직전에 `S.stem` 을 바꾸면 화면 그대로 + flash `상자 0개 저장 (그 사이 사진을 바꿔 화면은 그대로 둡니다)`.
📄 **저장 실패**(`ok:false`): 화면을 덮어쓰지 않고 «저장 안 됨» 도 그대로 둠.

### ⑶ 손잡이 반경 상한

📄 배율 0.03x · 100×100 상자: **예전 반경 233.3 이미지px → 이제 33.3**(짧은 변의 1/3).
📄 `hitHandle(0,150,150)`(상자 가운데) → 예전 `"nw"` → 이제 `null`, mousedown 이 `mode=move` 로 잡힘 → **축소 상태에서 옮기기가 된다.**
📄 회귀: 배율 1x·200×200 상자에서 `nw/ne/sw/se` 네 모서리 그대로, 모서리에서 6px 안쪽도 잡힘(반경 7 유지), 가운데는 안 잡힘.
📄 10px 짜리 작은 상자: 모서리는 잡히고 **가운데는 안 잡힘**(전에는 반경 7 이라 어디를 눌러도 크기조절이었다).
📄 배율 6가지(0.03~30) × 상자 크기 6가지(3~1000) = **36가지에서 «가운데» 가 모서리로 안 잡힘.**

### ⑷ 겹친 상자 순환

📄 큰 상자 `[0,0,400,400]` 안에 작은 상자 `[100,100,150,150]`, 같은 자리(125,125) 5번 클릭 → 고른 순서 **[1,0,1,0,1]** (위→아래→위…).
📄 3겹(`400`·`250`·`50`) → **[2,1,0,2]** 로 순환.
📄 다른 자리(300,300) 를 거친 뒤 다시 누르면 **맨 위부터**(순환 초기화). 1px 떨림(≤3화면px)은 «같은 자리» 로 보고 순환, 20px 떨어지면 맨 위.
📄 순환을 6번 해도 `bundo=0 bDirty=false`. 빈 곳 클릭은 `bsel=-1`(전과 같음).
