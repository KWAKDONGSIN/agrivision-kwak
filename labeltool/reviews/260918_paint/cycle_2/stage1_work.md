## 1. A~D — 한 것 / 안 한 것

### A. `status.json` 의 새 칸 — **`confirmed` 하나만 늘렸습니다**(`src` 는 안 씁니다)

```json
{ "status": "exclude",
  "by": "AI 3회 검수(Opus5→Opus5→Fable5.1)",
  "at": "2026-09-18 03:12:44",
  "note": "중복: 20150919_174151_image96",
  "prev": { "status": "exclude", "note": "중복: …", "by": "AI 3회 검수(…)" },
  "confirmed": { "status": "exclude", "by": "곽동신", "at": "2026-09-18 13:05:16", "note": "" } }
```

- **`confirmed`** = 사람이 확정한 판정. 없으면 «미확정». `status`·`by`·`at`·`note`·`prev` 는 **한 글자도 안 바꿉니다**
  (실측: §5-3 표의 «AI 제안(status·by·note·prev) 그대로» 통과).
- **`src`(`ai`/`human`) 는 파일에 쓰지 않고 읽을 때 계산합니다** — 설계안(§6-1)과 **다릅니다. 이유:**
  🔴 **`status.json` 의 `src` 칸은 이미 다른 뜻으로 쓰이고 있었습니다** —
  `server.py` 1241·1341행이 «어느 단추가 이 제외를 넣었나»(`dup_bulk`·`dup_group`)를 거기 적고,
  「일괄 제외 되돌리기」·「묶음 되돌리기」(1283·1375행)가 **그 값만 보고** 되돌립니다.
  거기에 `"ai"`/`"human"` 을 쓰면 그 표식을 덮어 **되돌리기가 망가집니다.**
  → `src_of(rec)` 는 값이 `ai`/`human` 일 때만 그것을 믿고, 그 밖(=`dup_bulk` 등)이거나 없으면
  `by.startswith("AI")` 로 미룹니다. **마이그레이션 0 · 옛 코드 영향 0.**
  (전용 시험 ⑥-b: 일괄 제외 → 그 사이에 확정 → 되돌리기 → 되돌아가고 확정은 남는다. 통과.)
- **쓰는 곳은 한 군데뿐** — `confirm_status(fruit, pairs, by, note)`(server.py 439~462행).
  `POST /api/status` 의 `confirm:true` 갈래만 이 함수를 부르고, **기존 `status:<과일>` 자물쇠 안에서**
  한 번 읽고 한 번 씁니다(묶음째여도 한 번에 — 반만 저장되는 일이 없습니다).
- **`/api/save`(마스크 저장)·`/api/save_instances`(번호 저장)·`/api/revert` 는 확정을 쓰지 않습니다.**
  설계안 §6-2 의 «마스크 저장도 확정으로 1줄» 은 **일부러 안 했습니다** — 그렇게 하면 이번 지시의
  «N-C 조작으로 `confirmed` 가 바뀌면 안 된다» 와 정면으로 부딪칩니다(§3 ❌ 표 참조).
  대신 **화면이** 저장 성공 뒤 사람이 `Enter`/`1~4` 를 누를 때 확정을 보냅니다.

  - 급한 경고(번호 오류·라벨 빠진 후보 …)가 머리말을 차지할 때도 **확정 딱지는 같은 줄에 남깁니다**:
    `⚠ 라벨 빠진 열매 후보 1곳  미확정 · [Enter]=맞다 🔍` (1차 실측에서 이 줄이 사라지는 것을 보고 고쳤습니다)

  **`Ctrl+S`(저장)는 확정이 아닙니다** — 저장 뒤 줄이 «✅ 저장됨 — `.` 로 다음 사진 · 맞으면 `Enter` 로 확정».
- **«☑ 내 큐»** 빠른 단추 = `sort=queue` + `confirmed=0`. 카드에 «✔ 확정 / 미확정» 딱지.
- **진행률** = «✔ 확정 30 / 전체 1001 · 오늘 나 30장 · 3.0% 확정 · 971장 남음» +
  그 뒤에 **AI 제안** 다섯 칸(이름을 붙여 «진행률이 아님» 을 말합니다).
- **묶음째 확정**: 중복 묶음의 **대표**에서 `Enter` → 확인창 **한 번** →
  «대표 = 쓴다(원본 OK, 사람이 방금 고쳐 저장했으면 «수정함»)» · «나머지 = 제외».
