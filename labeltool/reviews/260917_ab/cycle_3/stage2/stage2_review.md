## 9. 가정

1. **«현행» 의 기준은 `manifest.csv` + 폴더의 실제 파일**로 잡았습니다. `build_summary.json` 18개 값이 여기에 전부
   일치하므로 두 원천이 서로를 확인해 줍니다.
2. **검수 도중 총괄이 00:58(`--tool`)·01:04(재빌드) 작업을 했습니다.** 저는 **01:04 상태를 기준**으로 모든 숫자를

   그래서 **1단계 보고서의 «툴은 아직 v1» 관련 서술은 이제 전부 무효**입니다.
3. **«같은 포기 50쌍»** 은 v2 manifest 의 `rule_pending` 메모 문장(`A ↔ B ↔ C`)을 무향 쌍으로 펴서 셌습니다

4. **§2-2 의 «구멍»** 은 «A 와 B 가 같은 뺀 사진과 관계가 있다» 는 **2단 관계**이지, A–B 를 사람이 직접 보고
   «거의 같은 사진» 이라고 판정한 것은 아닙니다(직접 판정된 쌍이라면 애초에 한쪽이 빠졌을 것입니다).
