## 5. 내가 가정한 것

1. **«남긴 사진» = manifest 의 `action != excluded_duplicate`.** 첫 실행 때 값을 `exclude_duplicate` 로
   잘못 적어 결과가 전부 어긋났고, `action` 값 목록을 찍어 보고 바로잡았습니다(로그에 흔적 남김).
2. **세션·프레임 번호 파싱** — 사과는 `dataset*_{front,back}` 이면 앞 두 마디, 아니면 `_image` 앞까지.
   블루베리는 마지막 `_` 앞까지. 파일명 규칙이 다르면 §2-② 의 쌍 수가 달라집니다.
3. **최대 독립 집합**은 내가 짠 «성분 분해 + 차수≤1 축약 + 분기한정» 으로 풀었습니다(scipy·networkx 안 씀).
   값이 사이클 3 의 두 방법과 같아서 셋이 일치합니다.
4. **재검증 ①② 의 «거의 같은 사진» 판정은 내 눈 판정 한 벌**입니다 — 이 검수가 잰 일치도(사과 78~88%)를
   생각하면 내 판정도 그만큼 흔들립니다. 그래서 §2-② 는 «몇 장» 이 아니라 «있다/규모» 로만 말했습니다.
5. **실서버는 GET 만** 썼습니다. 로그인이 POST 라 금지되어, `app/server.py:64~73` 의 서명 규칙을 읽고
   쿠키를 직접 만들어 `GET /api/fruits` 한 번만 불렀습니다. 서버 상태는 바꾸지 않았습니다.
6. **PDF 는 1~12쪽만** 그림으로 봤습니다(지시 범위). 13~40쪽은 사이클 3 의 전 쪽 확인을 믿었습니다.
