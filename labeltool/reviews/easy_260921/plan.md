# 계획

1. 우선순위 1. 도구·되돌리기·진행·자동 단축키·쉬운 말·실수 방지. 브라우저에서 확인한다.
2. 우선순위 2. 팀원 자료를 읽기 전용으로 연결하고 요구 대조·상관계수 분석을 남긴다. 원본과 일치하는지 확인한다.
3. 우선순위 3. 실제 화면 사용법과 5분 시연 대본을 만든다. 390px를 확인한다.
4. 우선순위 4. 상자 배율 문제를 실제 마우스로 재현하고 잔재 목록을 갱신한다.
5. 보존한 기준선과 의도된 UI 변경을 대조하고 전체 회귀·별도 검수 후 안전하게 반영한다. 비밀 검사와 공개 반영·기록 후 EASY_DONE.
6. EASY_DONE 이후 후속 시연설명서 지시를 실행한다. 후보 각3장·실제 순서 리허설·폰 시연화면·PDF·예상질문·DEMO_DONE.
