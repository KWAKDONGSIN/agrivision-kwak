# 화면 용어 대조

| 이전 | 이후 | 뜻 |
|---|---|---|
| 마스크 | 칠한 영역 | 열매 위치를 칠한 그림 |
| 인스턴스 | 열매 번호 | 열매마다 붙은 번호 |
| Enter 확정 | 다 했어요 | 현재 판정을 사람이 확인하고 다음 사진으로 이동 |
| 테두리 채움 | 채우기 | 점을 찍고 Enter로 채우기 |
| 다시 | 다시하기 | 되돌린 작업 다시 실행 |

확인 상태와 AI 제안의 구분은 유지한다. «확정»은 저장 여부와 다른 데이터 의미이므로 상세 설명에는 «확인 완료»로 풀어 쓰고, 버튼 «다 했어요»와 구분한다. 그림 «저장»은 기존처럼 확인과 별도이며 저장 → 다 했어요 순서를 화면에 명시한다. 코드 식별자와 API 값은 바꾸지 않는다.
