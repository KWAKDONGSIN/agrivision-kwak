# 발표 준비자 메모

폰 대본은 운영 툴의 /static/시연.html, 전체 PDF는 /static/시연대본.pdf다. 서버가 안 되면 fallback/index.html을 폴더째 발표 PC에 복사해 열고 번호 순서대로 설명한다. 스크린샷만 복사하면 index의 상대경로가 끊기므로 폴더째 복사한다.

## 실제 연습 사본

시연 저장은 운영5111이 아니라 서버 안의127.0.0.1:5791과5792에 띄운 사본에서 두 번 검증했다. 이 포트는 외부 공개가 아니라 서버 안에서만 열린다. 발표 PC에서는 기존 SSH/원격개발 도구의 포트 전달 기능으로 같은 번호를 로컬에 전달한 뒤 http://127.0.0.1:5791을 연다. 발표 PC 자체에서 전달되는 경로는 이번 서버 환경에서 검증할 수 없으므로 미리 확인하고, 연결이 안 되면 오프라인 화면으로 바로 진행한다.

보안 관련 값·설정 세부는 공개본에서 생략했습니다.

발표자는 사용법 시연에서 사진 전체를 검수했다고 말하지 않는다. 포도 한 줄기 일부만 고치는 조작 예제이며, 사과의 가림 규칙은 교수님 결정 전이라 비교만 한다. 실제 업무에서 다 했어요는 사진 전체를 확인한 뒤 누른다.

## 결과와 증거

rehearsal1.json/log는 첫 전체 동작, rehearsal2.json/log는 최종 대본의 실제 시간표 재실행이다. 문서의31동작은 script_rows.json과 같다. scripts/ff.py로 브라우저를 조작했고 화면은 ~/ff_shots/demo_260921/에 촬영했다. 원본 data와 팀원 폴더에는 쓰지 않았다.

PDF는 기존260915 폰 문서와 같은96×172mm HTML 인쇄 형식이다. 추가 패키지 없이 기존 Firefox의 인쇄 기능을 이용했다. 모바일 폭·글자·인증·체크박스 저장은 check_docs.py, PDF 각 단어가 페이지 밖으로 나가지 않는지는 pdf_geometry.json에 기록한다.
