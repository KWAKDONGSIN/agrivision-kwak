## 무엇을 만드나
- 새 화면 `app/static/paint/` (그림판 모양: 왼쪽 도구 상자 · 아래 색 팔레트 · 맨 아래 상태 줄).
- **색 하나 = 열매 번호 하나.** 칠하면 그 번호의 열매. 마스크·번호·상자를 한 번에 다룬다.
  - 마스크 = 칠해진 곳 전부 / 번호 = 색 / 상자 = 같은 색의 바깥 네모(잎에 가려 두 조각이어도 한 상자).
- 도구 7개: 붓 · 지우개 · 채우기통(칠한 덩어리 클릭 = 지금 번호로) · 올가미(테두리 그리면 안을 칠함) · 스포이트 · 돋보기 · 손.
- 저장(Ctrl+S) = 마스크 수정본 + 번호 수정본 + 상자 를 기존 API 로 한 번에 저장(기존 data/ 경로·확정 규칙 그대로).
- «이 사진 빼기» 단추(흐린·근접 블루베리 등) = 기존 exclude.
- AI 판정(제안 마스크·flag·의심 목록·점수)은 **화면에서 전부 뺀다.** 파일은 지우지 않는다(연구 기록 · 통합 데이터셋 빌드가 읽을 수 있음).

## 주소
- `/` = 새 그림판 · `/old` = 옛 툴(데이터 정리·내보내기용으로 남김) · `/box` 는 그대로.
