# 구조 사이클 3 — 3차 판정

12장 스크린샷 바이트 동일, 36개 의미 있는 UI 상태 동일, 콘솔 오류 0, 실제 탭 클릭 8/8을 근거로 화면 분리 자체는 수용한다. 기존 공격 수집기의 탭 3차이는 시험이 옛 전역 함수를 직접 부른 문제이므로 제품 결함 주장은 기각한다. 시각 54칸과 PNG deBG 청크 차이는 관측 방식의 차이로 분리했다.

전역 window 속성 5개 잔존, 단축키 표와 실제 분기의 중복, UI를 통한 역방향 호출은 미완으로 채택한다. «3전역만/완전 단방향/단축키 단일 정의»라고 문서에 쓰지 않는다. 원래 의미와 호환성이 우선이며, 이 검수에서 해당 호출을 다시 설계하지 않는다.

구조 2와 합친 판은 회귀 1,102/0 및 API/내보내기 기준선 차이 0이다. 정적 지문 6칸 때문에 전체 명령 rc=1이므로 구조 5 전환 허가는 아직 아니다. 구조 4 문서·새 사람 시험을 진행한다.
