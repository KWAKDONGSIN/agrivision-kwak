## 독립 검증

첫 작업자의 `b3_struct3.py`를 재사용하지 않고 `../codex_resume/browser12.py`를 새로 작성했다. 네 과일 각 3장, 총 12장을 옛 화면과 새 화면에서 열었다. 마스크→상자→번호 36상태에서 stem·과일·모드·상자 수·번호 수·개수 문구·캔버스 크기·오류를 비교했다.

- 36상태의 위 의미 있는 값: 전부 동일.
- 사진마다 찍은 스크린샷: **12/12 파일 바이트 및 sha256 동일**, 다른 화소 0.
- 콘솔 오류: 옛 판 0, 새 판 0.
- 창: 1366×768 요청, 실제 스크린샷 1366×682(브라우저 화면 영역).
- 증거: `../codex_resume/evidence/browser12_{old,new,diff,screenshots}.json`, `~/ff_shots/260920_codex_browser12/`.

내부 canvas.toDataURL()의 지문은 36상태에서 달랐다. 이를 무시하지 않고 1280×720 창에서 별도 `browser_supplement.py`로 PNG를 해독해 확인했다. 비교 표본은 해독 화소 차이 **0**, 최대 채널 차이 **0**이며 PNG의 **deBG 부가 청크 16바이트만 달랐다**. 같은 문서 안의 반복 추출은 같았다. 따라서 canvas PNG 포장 지문을 화면 변화로 오인하지 않으며, 12장 판정 근거는 독립 WebDriver 스크린샷의 실제 바이트 동일이다. 36개 canvas 모두를 해독해 비교했다고 주장하지 않는다.

Claude가 남긴 `stage2/attack_js.py`를 새 사본으로 가져와 끝냈다. 32키×3모드, 마우스·휠·다각형·번호 도구·탭까지 130상태를 옛 판과 새 판에서 수집했다.

- 원시 차이 57칸: 확정 시각 문구 54 + 탭 상태 3.
- 시각만 정규화하면 탭 3칸이 남았다. 원인을 확인하니 시험이 존재하지 않는 `#tab-list` 등을 클릭한 뒤, 실패하면 옛 전역 `showView()`를 불렀다. 새 화면에서는 함수가 `UI.showView`라 예외가 났지만 시험이 이를 삼켰다. 사용자 화면의 실패로 판정할 수 없다.
- 실제 `nav button[data-view=...]`를 클릭하는 별도 경로로 목록·현황·데이터 정리·편집을 옛 판/새 판 각각 검증: **8/8 전환 일치**, 오류 0. `browser_supplement.json`.
- `k_normal_1`은 양쪽 모두 확인창 때문에 상태 수집 예외가 있었다. 130개 전부 성공한 단정이라고 쓰지 않는다. 이름/판정/확정 흐름은 별도 전체 브라우저 b1 81/0, t2 27/0으로 보완했다.

## 1차 주장 수정·미달

1. «전역 152→3»은 lexical binding만 센 수치다. `window.zoomToNote`, `SEEDSRCKO`, `seedSrcKo`, `renderCntChip`, `expOpen` 5개는 남았다. «전역 셋만» 목표는 미완.
2. KEYS 표는 설명/검사용이고 실제 keydown 분기는 별도 switch/handler다. 완전한 단일 정의가 아니다. u7 69단정이 괴리를 일부 잡지만 구조 목표 완료로 쓰지 않는다.
3. UI를 통한 나중 모듈 호출이 있다. 로딩 순서는 단방향이지만 실행 의존은 완전한 단방향이 아니다.
4. sim.js의 배율 2x/3x 예제는 손으로 쓴 옛 알고리즘이다. 실제 boxes.js는 전체 이동량을 계산하므로 옛 예제를 곧바로 현재 결함이라고 부르지 않는다.
5. ⑤ 정적 지문 6칸 차이와 전체 명령 rc=1을 남긴다. 원래 기준선은 바꾸지 않았다.

## 시험 도구 수정·안전 기록

새 browser12 시험은 초기 두 실행에서 wait 인자 오류와 Firefox WebDriver의 lexical 변수 직접 접근 오류로 중단됐다. 각 실패 로그와 스크립트 사본을 보존하고, 도구의 `L.ev()`로 접근해 성공했다. 제품 코드는 고치지 않았다. 기존 공격 도구의 reset_status 자기 자신 복사는 사본에서만 가드했다. 제품을 이 시험에 맞춰 바꾸지 않았다.

모든 쓰기·삭제 동작은 모래상자에만 있고, 제거되는 파일은 `_archive/`로 옮겼다. 생성한 서버·브라우저는 자기 PID만 닫았다. 실서버/원본 app·data sha256 변경 0을 구조 2와 함께 확인했다.
