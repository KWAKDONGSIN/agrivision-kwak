# 구조 사이클 5 — 독립 검수

전체 회귀를 같은 명령으로 반복해 자기 시험을 재사용하지 않았다. 별도 `stage5_independent_read.py`는 이전 서버/최신 후보의 새 사본을 각각 만들고 실제 고정12장에 대한 item·boxes 24개 JSON 응답의 원시 바이트 SHA-256을 비교했다. **24/24 동일, 정규화 없음**. 전체 응답 본문도 증거 JSON으로 남겼다.

정적 교체 세 주소의 이전/새 파일을 직접 읽어 bytes와 SHA-256을 보조 관문 정책에 대조했다. 여섯 파일 대응은 모두 맞는다. 따라서 원래 기준선 불일치는 숨겨진 API 변경이 아니라 의도한 HTML/JS 교체다. 그렇더라도 사용자의 «기준선 통과 못하면 전환 금지»를 보조 관문만으로 덮어쓰지 않는다.

회귀 로그·bundles.tsv를 별도로 읽었다. 1,124/0은 단정 수이며, baseline/check rc1은 합계 숫자에 잡히지 않는다. 원래 합격 기준(①②③⑤) 차이6개, 전체 마지막 문구 실패를 채택한다. 정상 API/산출물은0차이. 추가 관문은8/0·rc0으로 별도 표기한다.

입력 보존: 직전 별도 SHA 검사에서 정본 app82·data7,397 변경0, PID1467097 유지. 운영 Python·정적 코드의 재복사 및 재시작은 없었다. 폰용 신규 문서 파일을 뒤에 추가한다면 기존 코드 교체와 구분해 목록과 인증 검사를 남긴다.

구조 지표: server.py2052→93줄. Python5파일3432줄→24파일3997줄(호환·__init__포함). 활성 JS는2파일4001줄→12파일4309줄이며 새 호환 로더2개를 포함한 실제 JS파일은14개다. 이전 Python 복원본에 새 JS가 섞인 흔적이 있어 그 폴더의 JS glob 수를 역사적 이전값으로 쓰지 않았다. 올바른 이전값은 실제 브라우저 A/B에 쓰인 old/app.js·ui.js에서 셌다.
