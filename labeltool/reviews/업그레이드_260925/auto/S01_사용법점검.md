# S01 그림판 사용법 문서 점검 (r1)

대상: `kds0206/문서/260923_그림판툴_사용법.md` (최종 수정 09-24). 기준: `app/static/paint/index.html` · `paint.js`(코드 직접 대조, 실서버 화면은 띄우지 않음).
문서는 고치지 않았다. 아래는 틀린 곳·빠진 곳 목록이다.

## A. 틀린 곳 (고쳐야 함)
1. **§도구 ✨ — «같은 자리를 다시 누르면 다른 모양(알 하나 → 크게 → 송이)».** 순서를 보장하지 않는다. 후보는 SAM 점수 내림차순(`ai_helper/sam_server.py` 73줄 `argsort(-scores)`)이라 «알→크게→송이» 로 늘어나는 게 아니다. 화면 도움말은 «작게/크게», 상태줄은 «N/M번째 모양» 이라고만 한다. → «다시 누를 때마다 후보 모양이 돌아가며 바뀜(후보 수는 사진마다 다름)» 으로.
2. **§도구 표 — 돋보기 행에 «휠 = 확대, 스페이스+끌기 = 옮기기» 만 있고 돋보기 도구 자체 동작이 없다.** 실제는 돋보기(Z) 왼쪽 클릭 = 확대, 오른쪽 클릭 = 축소(`paint.js` 737줄, ×1.6). 휠·스페이스는 모든 도구에서 된다는 점도 표에서는 돋보기/손 전용처럼 읽힌다.
3. **§붓 옵션 «다른 열매 위에는 안 칠함».** 붓 전용처럼 적혀 있으나 올가미·✨ 에서도 같은 옵션이 뜨고 적용된다(`paint.js` 704~715줄, 499줄). ✨ 는 이미 번호 있는 열매 위를 누르면 «먼저 오른쪽 클릭으로 지우라» 고 거절한다 — 문서에 없다.
4. **§도구 표 — 올가미 행.** 오른쪽 클릭 = 안쪽 지우기(올가미)가 빠져 있다. 반대로 «오른쪽 = 지우기» 는 붓 행에만 적혀 있어 도움말(모든 도구 공통)과 다르다. 지우개·스포이트·손 제외 모두 오른쪽이 지우기.
5. **§자주 하는 일 — «표본 60장 기준 … 사과 93% · 블루베리 86% · 포도 80% · 복숭아 97%» 와 «마스크 mAP50 0.84».** 코드·`ai_helper/draft/` 안에서 근거 파일을 못 찾았다(`v3_result.txt` 는 파일럿 평가로 사과 0.888 · 블루베리 0.825 · 포도 0.884 · 복숭아 0.942, 평균 0.885). 0.84 가 어느 평가 값인지 미확인 → 근거 파일 경로를 적거나 «약 0.85~0.89(파일럿 평가)» 로. **확인 못 함** 으로 남긴다.

## B. 맞는 것 (코드로 확인)
- 도구 키 B·E·F·L·I·Z·H·S·N, V(원본 보기), ` 누르는 동안 원본, Ctrl+S 저장, 채우기통 오른쪽 = 덩어리 지우기, 스포이트, 회색(=번호 없는 곳) + 채우기통으로 번호 붙임.
- ✨ 끌어서 네모, Shift+클릭 = 떼어 내기, 오른쪽 = 열매 통째로 지우기.
- 채우기통 옵션 두 개(«누를 때마다 새 번호» / «지금 색 그대로»).
- 원본 보기 단추 문구, «사진은 부드럽게 · 색 칸만 또렷»(`paint.css` 58줄 `#ov{image-rendering:pixelated}`).
- 파일 메뉴: 모델 초벌 «빠진 열매만 더하기»(노란 동그라미, `paint.js` 323줄) · «이 사진 빼기». 목록 ✓ = 저장, ✕ = 뺌(`paint.js` 128~129줄).
- `/old` 옛 툴 링크, 첫 화면 `/`.
