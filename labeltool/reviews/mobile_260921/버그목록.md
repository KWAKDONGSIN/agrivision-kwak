# 모바일 검수 발견 사항

1. 기존 ID 선택자가 확대/포도 번호 단추의 크기를 덮어서44px에 못 미침. 모바일 최소 크기를 우선하도록 고쳤고30개 배치 검사 재통과.
2. 새 번호 적용 단추가 기존 .tools 선택자 때문에 PC에도 나타날 수 있음. 전용ID로 PC 숨김 규칙을 명시. PC12장 픽셀 차이0.
3. 터치취소 때 번호 임시 영역을 지워도 numBrushing 플래그가 남음. 취소 시 해당 플래그도 해제. 실제 번호 픽셀은 미변경.
4. 시험에서 판정 후 자동으로 다음 사진으로 가는데 원래 사진만 조회하여 좋음 판정을 실패로 오판. 판정 전 해당 사진을 다시 여는 시험으로 수정. 제품 규칙 변경 없음.

5. 별도 실제 포인터 검수에서 목록20번째 사진을 열면 scrollY738이 남아 사진 위쪽이 화면 밖으로 나감. 모바일의 사진 이름/편집화면 변경을 관찰해 스크롤을 맨 위로 복구한다.

6. 모바일 번호 임시 붓 영역은 기존 번호 Undo 기록에 아직 없어서 하단 되돌림으로 취소되지 않음. 미완성 영역이면 기존 Escape 처리로 취소하고, 적용된 번호는 기존 Undo를 호출한다.

7. 터치 중 번호 안내 문구가 상단에서 여러 줄이 되면 캔버스 위치가 달라져 다음 터치 좌표가 어긋남. 폰 안내 메시지는 레이아웃을 밀지 않는 고정 알림으로 변경한다.
