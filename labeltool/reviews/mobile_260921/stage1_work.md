# 작업 단계

모바일 지시서 순서대로 사본에 화면·입력만 추가했다. 운영 app과 data의 착수 지문은 evidence/pre_*_sha256.json, 백업은 _archive/pre_mobile_260921이다.

- 기존 viewport를 유지하고 mobile.css를 추가했다. 820px 이하에서만 세로 배치, 16px 여백, 44px 터치, 16px 글자, 안전 영역을 적용했다.
- 사진·도구·판정 순서, 하단 이전/확정/다음/되돌림, 목록 탭으로 접힌 목록을 연다.
- mobile.js는 기존 상자·번호·확정 손잡이를 호출한다. 두 손가락 전환과 touchcancel은 미완성 그리기를 취소한다. 정밀 마스크는 PC 안내와 입력 차단을 적용했다.
- 로그인은 CSS만 수정했다. 서버 API와 데이터 규칙은 수정하지 않았다.
- Firefox 요청 창 크기는 최소 폭500으로 제한됐다. 같은 출처 iframe의 실제 innerWidth/Height를 390×844와360×740으로 측정했다. 원본 화면은 ~/ff_shots/mobile_260921에 보존했다.
- PC12장 비교는 픽셀 차이0이다. 실제 viewport1366×682(창1366×768)이며, 포도 번호 비활성 상태도 그대로 비교했다.
- 폰 배치30개 검사 통과. 합성 터치와 전체 회귀는 별도 사본에서 진행 중이다. 실기기 확인은 못 했다.
