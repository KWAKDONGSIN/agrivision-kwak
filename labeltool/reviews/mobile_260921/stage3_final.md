# 모바일 대응 최종 판정

모바일 기능·별도 검수·전체 회귀를 통과해 운영에 반영했다. 정밀 마스크는 PC에서 하도록 안내하고 폰 입력을 막았다. 기존 API/데이터 규칙을 변경하지 않았다.

HTML5종만 의도된 길이/지문 변경으로 기준선에 반영했다. 이전 기준선은 tests/fixtures/baseline_pre_mobile_260921에 보존했다. 코드 지문 차이와 기존 회귀 묶음 추가 경고는 실패가 아니다. 초기 전체시험 결과와 HTML 전용 대조도 evidence에 따로 보존했다.

## 운영 반영

2026-09-21 04:29:11에 최근15분 외부 접속0,운영 app/data 착수 지문 동일,시험 사본 지문 동일을 확인한 뒤 tmux에서 bash app/run.sh restart를 실행했다. PID3690052에서155257로 전환했다. data는 그대로다. 변경11파일은 evidence/deploy.json에 기록했다. 워치독과 기존 시연용5791 서버는 유지했다.

## 팀원에게

툴을 새로고침해 사용한다. /static/mobile_done.html에서390px 전후 화면과 가능한 작업 표를 볼 수 있다. /static/how_to.html#mobile에 폰 사용법을 추가했다. 목록→사진 확인→원본 OK/문제 판정이 우선이며, 하단 이전/확정/다음/되돌림을 이용한다. 상자와 번호는 간단 편집과 저장만 하고 정밀 편집은PC에서 한다.

## 검증 한계

실기기 확인은 못 했다. Firefox 외부 창은 최소폭500이므로 같은 출처 iframe으로 실제390×844와360×740을 재현했다. 터치는 실제 등록한 이벤트 손잡이에 합성 입력을 보냈다. PC 창1366×768의 실제뷰포트는1366×682이다. 포도 번호 비활성 상태까지 기존과 같다. 실제폰 홈바와 손가락 감각은 검증했다고 주장하지 않는다.
