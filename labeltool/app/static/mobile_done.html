툴 열기 · 폰 사용법

폰에서는 보고, 판정하고, 넘기세요.

과일과 사진을 고르면 목록이 접히고 사진이 나옵니다. 사진 아래 «원본 OK»는 좋음, «문제»는 문제 있음으로 기록합니다. 하단 «확정»은 현재 판정을 확인 완료로 기록합니다. «이전 / 다음»으로 이동하고 실수하면 «되돌림»을 누르세요.

정밀 마스크 편집은 PC에서 하세요. 폰에서는 칠하기를 막고 사진 확인에 집중했습니다.

할 수 있는 일

작업폰에서
좋음·문제 판정가능. 사진을 보고 해당 단추를 누릅니다.
사진 확대·이동두 손가락으로 확대하거나 함께 움직입니다. «맞춤»으로 전체 사진을 봅니다.
진행·현황·데이터 정리가능. 위쪽 탭에서 확인합니다.
상자 그리기·삭제한 손가락으로 크게 그리고, 고른 상자를 삭제합니다. «상자 저장»을 누릅니다.
번호 추가·삭제크게 칠한 뒤 «칠한 번호 붙이기», 번호를 고른 뒤 «고른 번호 삭제»를 누릅니다. «번호 저장»으로 남깁니다.
정밀 마스크·번호 나누기·합치기PC에서 합니다.

확인한 범위

Firefox에서 390×844와360×740의 실제 화면 영역으로 로그인·목록·편집·현황·데이터 정리를 확인했습니다. 가로 넘침이 없고, 단추는 최소44×44px, 본문과 입력은16px 이상입니다. PC12장은 전후 픽셀 차이가 없었습니다.

Firefox의 창 최소 폭이500px이어서, 같은 출처의 고정 크기 화면(iframe)으로 정확한 폰 폭을 재현했습니다. 터치 이벤트는 합성 입력으로 검증했습니다. 실기기 확인은 못 했습니다. 아이폰 홈바·실제 손가락 감각은 기기에서 추가 확인이 필요합니다.

시험은 별도 사본에서 했습니다. 위 사진의 숫자를 팀의 실제 검수 실적으로 세지 않습니다.
