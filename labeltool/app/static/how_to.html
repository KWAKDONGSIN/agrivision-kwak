툴로 돌아가기

사진 한 장, 세 걸음

고르기 → 고치고 저장 → 다 했어요.

잘못 칠해도 Ctrl+Z로 되돌립니다. 원본은 읽기만 합니다. 아래 사진은 실제 브라우저로 촬영한 시험 사본이며, 사본의 숫자를 팀의 실적으로 세지 않습니다.

1. 들어가기

팀에 공유된 툴 주소를 열고 비밀번호로 들어갑니다. 오른쪽 위 «내 이름»을 적고 첫 안내3장을 읽습니다. 비밀번호 값은 이 문서에 적지 않습니다.

2. 사진 고르기

과일을 고르고 사진 카드를 누릅니다. 사진 번호를 알면 검색합니다. 연습 화면은 실제 존재하는 포도500번입니다.

3. 잘못된 곳 고치기

지우개로 잘못 칠한 곳을 지우고, 붓으로 빠진 곳을 칠합니다. 굵기는 슬라이더, 확대는＋확대, 옮기기는 이동입니다. 실수하면 큰 «되돌리기»를 누릅니다.

4. 저장하고 다 했어요

아래 «저장»을 누르고 고친 그림을 눈으로 확인합니다. 이어서 «다 했어요»를 누르면 현재 판정이 확인 완료로 기록됩니다. 실제 검수에서는 사진 전체를 확인한 뒤 누릅니다. 저장만으로는 이진 그림의 확인이 끝나지 않습니다.

5. 다음 장

확인이 성공하면 다음 사진으로 갑니다. 현재 목록의 마지막 사진이면 같은 자리에 남습니다. 다음 사진은 위쪽▶ 또는 점(.) 키입니다. 저장 안 한 수정이 있으면 먼저 경고합니다.

6. 다 끝나면

실제 작업에서는 현황에서 사람이 확인한 장수를 볼 수 있습니다. 팀원은 여기까지 하고 창을 닫으면 됩니다. 데이터 정리에서 파일로 내보내는 일은 담당자가 진행합니다.

팀원 자료도 여기서

데이터 정리의 포도 삭제대상 목록에서 번호를 누르면 사진이 열립니다. 기존99장과 최인훈 추가103장의 출처를 구분합니다. 제외돼 현재 목록에 없는 사진은 원본 보기로 열립니다. 클릭만으로 삭제하거나 제외하지 않습니다.

사과는 정렬에서 «박성문 사과 우선 검수»를 고릅니다. 사진 위 «의심 개체 표시»를 켜면 후보가 점선으로 보입니다. 자동 후보는 오류 확정이 아니므로 사진을 먼저 확인합니다.

폰에서 하는 법

과일과 사진을 고르면 목록이 접히고 사진이 나옵니다. 목록을 다시 보려면 위의 «목록»을 누르세요. 아래 고정된 «이전 / 확정 / 다음»으로 사진을 넘깁니다. «확정»은 현재 판정을 확인 완료로 기록하므로, 사진을 먼저 살펴보세요.

사진 아래로 내려가 «원본 OK»(좋음) 또는 «문제»를 누르면 해당 판정이 기록됩니다. 현황에서 사람이 확정한 장수를 보고, 데이터 정리에서 정리할 자료를 확인합니다.

두 손가락을 벌리면 확대되고 함께 움직이면 사진이 이동합니다. «맞춤»으로 전체 사진을 다시 봅니다. 상자는 한 손가락으로 그리거나 고른 뒤 삭제합니다. 번호는 열매를 누른 뒤 «고른 번호 삭제», 크게 칠한 뒤 «칠한 번호 붙이기»를 누릅니다. 실수하면 아래 «되돌림»을 누르세요. 고친 상자·번호는 각 저장 단추로 저장합니다.

정밀 마스크 편집은 PC에서 하세요. 폰에서는 마스크 칠하기를 막았습니다. 번호의 정밀 나누기·합치기도 PC에서 합니다.
