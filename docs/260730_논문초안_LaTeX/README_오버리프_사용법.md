## 1. 먼저 알아야 할 것 — LaTeX가 뭔가

교수님이 미팅에서 설명하신 그대로입니다 (녹취록 33:52).

> "워드나 한글처럼 문서 편집하는 건데, **PDF로 변환해서** 레이아웃을 해요.
> 그래서 논문 출판용으로 많이 씁니다."

즉 **`.tex` = 원고(글자만) → 컴파일 → `.pdf` = 예쁘게 배치된 논문** 입니다.
Overleaf 는 그걸 **웹브라우저에서** 해주는 사이트입니다. 설치할 게 없습니다.

## 3. Overleaf에 올리기

교수님이 이미 프로젝트에 초대해 두셨습니다 (녹취록 33:42 *"제가 오버리프에 초대를 보냈거든요"*).

### 이미 있는 프로젝트에 넣는 경우 (이쪽을 권장)

1. Overleaf 접속 → 교수님이 초대한 프로젝트를 엽니다
2. 왼쪽 파일 목록 위의 **Upload** 버튼(↑ 모양) 클릭
3. `main.tex` 와 `references.bib` 를 끌어다 놓습니다
4. ⚠️ 기존에 `main.tex` 가 이미 있으면 **덮어쓰기 경고**가 뜹니다.
   덮어쓰기 전에 기존 파일 이름을 `main_old.tex` 로 바꿔 두세요. (남의 작업이 날아가면 안 됩니다)

### 새 프로젝트로 만드는 경우

1. Overleaf → **New Project → Upload Project**
2. 두 파일을 zip으로 묶어서 올립니다

## 4. 🔴 제일 중요 — Springer 템플릿 파일이 있어야 컴파일됩니다

`main.tex` 첫 줄이 이렇게 되어 있습니다.

```latex
\documentclass[pdflatex,sn-apa]{sn-jnl}
```

`sn-jnl` 은 **Springer Nature 공식 템플릿**입니다. 이게 프로젝트에 없으면
"File `sn-jnl.cls' not found" 같은 빨간 에러가 납니다. 놀라지 마세요, 정상입니다.

**해결 방법 (둘 중 하나)**

- **A안 (쉬움)** — Overleaf 에서 **New Project → Templates** 로 가서
  `Springer Nature LaTeX Template` 을 검색해 새 프로젝트로 만든 다음,
  그 프로젝트 안에 우리 `main.tex` 와 `references.bib` 를 덮어씁니다.
  템플릿에 딸려 오는 `sn-jnl.cls`, `sn-apa.bst` 등이 그대로 남아 있어 바로 컴파일됩니다.
- **B안** — 교수님이 만드신 프로젝트에 이미 템플릿이 들어 있다면 그냥 4번은 건너뛰면 됩니다.

## ⚠️ 먼저 알아둘 것 — 이 서버에서는 컴파일 검증을 못 했습니다

솔직히 적습니다. **이 서버에는 LaTeX 컴파일러가 설치돼 있지 않습니다**
(`pdflatex`, `latexmk`, `xelatex` 전부 없음 — 직접 확인). 그래서 제가 한 검증은 여기까지입니다.

| 검증한 것 | 결과 |
|---|---|
| 중괄호 `{` `}` 짝이 맞는지 | ✅ 246 : 246 으로 일치 |
| `\begin{document}` / `\end{document}` | ✅ 각 1개 |
| 그림 파일 존재 | ✅ `figures/` 에 4장 복사해 둠 |
| **실제 PDF 컴파일** | ❌ **못 함 — Overleaf 에서 처음 돌려봐야 합니다** |

→ 첫 컴파일에서 에러가 날 수 있습니다. 대부분은 4번 항목(템플릿 파일 없음)이 원인입니다.
에러 메시지를 그대로 복사해 주시면 고쳐 드리겠습니다.

## 6. 빨간 글씨 `[TODO: ...]` 는 뭔가

아직 못 채운 곳입니다. 일부러 **빨간색**으로 해뒀습니다. 눈에 띄어야 안 빠뜨립니다.

- **Results / Discussion** 은 통째로 TODO 입니다 → 실험이 끝나면 채웁니다.
  교수님 지시도 그랬습니다 (녹취록 45:18 *"실험 결과는 우리가 이제 못하지만은 ...
  앞에 부분은 쓸 수 있잖아요"*).
- **Introduction / Related work / Datasets / Methods** 는 **다 써 있습니다.**
  읽어보고 사실과 다른 게 있으면 고치면 됩니다.

TODO를 다 채우면 `\todo{}` 명령을 지우면 되고, 빨간 글씨는 저절로 사라집니다.

## 7. 그림 넣기

`main.tex` 는 `figures/` 폴더의 그림을 찾습니다. 아직 없으면 **네모 자리표시자**가
대신 나오므로 **그림이 없어도 컴파일은 됩니다.**

포도 실험 그림은 서버 이 경로에 생깁니다.

```
semantic-segmentation/reports/grape_toy/figures/
  fig_loss_curves.png      학습·검증 loss 곡선
  fig_val_fg_iou.png       에폭별 검증 IoU
  fig_test_bar.png         조합별 test IoU 막대
  fig_per_image_box.png    사진별 IoU 분포
```

Overleaf 에 `figures` 라는 폴더를 만들고 이 그림들을 올리면 자리표시자가 사라집니다.

## 8. 팀원과 겹치지 않게 하는 요령

Overleaf 는 여러 명이 **동시에** 고칠 수 있습니다(구글 문서처럼). 그래도 안전하게 하려면:

- 최인훈 님이 **Method 의 모델 선정 파트**를 맡기로 했습니다(0730 카톡) →
  그 절(`\subsection{Segmentation head selection}`, `\subsection{Backbone selection...}`)은
  **곽동신이 먼저 손대지 말고** 최인훈 님과 맞춰보세요.
- 대신 곽동신은 **Datasets 절의 포도(CERTH) 부분**과 **Pilot experiment 절**이
  본인 담당입니다. 실제로 돌린 사람이 본인이기 때문입니다.
