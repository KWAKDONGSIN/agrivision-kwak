# 복숭아 재학습 한 바퀴 — 준비 완료, 실행은 지시 대기

## 왜 지금인가
교수님이 0908 에 «AI 초벌 → 사람 체크 → 재학습» 을 만들라 하셨고, 재학습은 그 과일에서 사람 판정이
30% 이상 쌓였을 때 돌리기로 문서에 적어 두었습니다(`ai_pass/retrain_loop.md`).

- 복숭아 판정 현황: **125장 중 116장**(수정 39 · 원본 OK 77) = 93%. 기준을 넘었습니다.
- 남은 9장은 사람이 봐야 하는 flag 30장 중 일부입니다. 이건 기다리지 않아도 한 바퀴 돌릴 수 있습니다.

## 실행하지 않은 이유
작업기록의 «절대 하지 말 것» 에 **사용자 확인 없이 GPU 학습 실행 금지**가 있습니다. 그래서 명령만 준비했습니다.

## 돌리면 이렇게 됩니다
- 범위: 파일럿0 과 같은 4회전(t1v2·t2v3·t3v4·t4v1), 800 epoch, 같은 손실·옵티마이저·증강
- 데이터: `masks_fixed/` 를 끼운 수정판 복숭아 (원본은 건드리지 않음)
- 시간: GPU 1장이면 약 4시간, 4장에 나누면 약 1시간
- 산출: 새 체크포인트 → 새 AI 제안 → 이전 제안과 Dice 비교(«좋아졌나»)

## 실행 명령 (지시하시면 제가 이 순서로 합니다)
```bash
nvidia-smi                       # 빈 GPU 확인
# platform/GPU점유.md 에 한 줄 기록
GPU=0 bash /data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴/ai_pass/retrain_and_repropose.sh peach 1
```
- 4회전을 GPU 0~3 에 나눠 돌리려면 회전별로 `CUDA_VISIBLE_DEVICES` 를 달리해 `nohup` 으로 띄웁니다.
- 스크립트는 2026-09-16 에 쓴 초안이고 아직 한 번도 돌지 않았습니다. 처음 돌릴 때는 2 epoch 스모크로 배관을 먼저 확인하는 것이 안전합니다.
