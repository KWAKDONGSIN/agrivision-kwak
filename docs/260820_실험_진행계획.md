## 3. 관문 — 본 실험 전에 끝나야 하는 것

1. 🟡 헤더 9 × 백본 6(7) 확정 — 교수님이 주말에 서버 클로드로 근거 검토 후 다음 미팅
2. 🟡 test 평가 = 센터크롭 / 슬라이딩 윈도우 결정 (바뀌면 전 실험 재산출이라 먼저 정해야 함)
3. ❓ 고정 설정(512/BCEDice/AdamW/200ep) 근거 논문 — 현재 0건, 교수님 「빠진 근거」 검토 대상
4. 공용 `main` 코드 정리 커밋 + 팀원 최신 코드 합류(박성문 `backbone_unet.py`·`unet.py` 는 이미 병합됨)
5. 4명 GPU 분담표 (`GPU점유.md`)

## 4. 한 런이 하는 일 (코드 기준)

```
configs/<데이터>_<head>_<backbone>_bcedice_cv<N>.yaml
   → tools/train.py  : 학습 + 매 에폭 val, best = val_loss 최소, 조기종료
   → output/<head>_<backbone>_bcedice_cv<N>/  : ckpt · training_history.csv · TensorBoard
   → tools/val.py --split test : test 평가 (현재 CenterCrop 512)
   → tools/aggregate_results.py : 전 런 CSV 집계 (output/results_summary.csv)
   → reports/ : 표·그림·Friedman (tools/make_*.py)
```
yaml 이름 규칙은 집계 스크립트가 정규식으로 읽으므로 **바꾸면 안 됩니다.**
