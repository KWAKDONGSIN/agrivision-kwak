# 공격적·보통 검수 최종 종합

**후보의 시험한 동작과 인수인계는 확인했습니다. 구조 목표는 부분 달성이고, 운영 코드 전환은 보류합니다.**
원래 엄격 기준선에 정적 응답6칸 차이가 남아 사용자 전환 조건을 만족하지 못했습니다. Codex가 임의로 기준선을 다시 뜨거나 보조 검사로 실패를 지우지 않았습니다.

Fable이 별도로 판정한 것이 아닙니다. 사용자의 대행 지시에 따라 같은 Codex가 작업과 두 검수를 분리하고 마지막 종합을 작성했습니다. 새 사람 인수인계 시험만 별도 에이전트가 맥락 없이 수행했습니다.

## 기각하거나 범위를 좁힌 것

- «표시 이름이 AI로 시작하면 모든 저장API가 거절해야 한다»: 기존 결정은 /api/status에만 적용됩니다. 상자저장200을 새 구조 회귀라고 분류하지 않습니다. 이름 칸은 신원 인증이 아닙니다.
- «후보 ff.py는 주소를 안 주면 실서버에 접속한다»: 후보는 geckodriver 생성 전 중단함을 새 검사로 확인했습니다. 운영 스크립트까지 고쳐졌다는 주장은 하지 않습니다.
- «스크린샷·유한 표본이 같으므로 모든 경우 동작 무변경»: 시험한12장과 입력 범위의 근거입니다. 무한한 입력/동시편집/다른 브라우저까지 증명하지 않습니다.
- «구조를 완벽하게 정리했다»: 잔존 항목 때문에 부분 달성이 맞습니다.

## 실제 근거

- 최신 전체 회귀: 단정1124/0,527초. 원래 API/산출물0차이, 정적6차이로 전체 실패 표시.
- 독립 실제12장 item·boxes API24응답: 정규화 없이 원시바이트 동일.
- 독립 합성 네 과일×3장 내보내기60파일: CSV 이름·시각·경로 포함 원시sha256 동일.
- 화면12장 스크린샷:12/12 바이트 동일. 새 최종 보통 검수도 실제 로그인/사진/개수/내보내기 화면 확인.
