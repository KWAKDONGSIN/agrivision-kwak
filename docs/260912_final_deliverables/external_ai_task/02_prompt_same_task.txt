나는 데이터사이언스 초보 대학원생이야. 지도교수님이 세운 실험 설계 문서(첨부: 01_입력자료_교수님프로토콜원문.md)를 다음 주 월요일 랩미팅에서 "내가 이해한 바대로" 5분 동안 설명해야 해. 교수님은 "12×12 다 못 하니까 20% 남겨서 한 게 있다. 그거 이해해서 워크플로우·순서도 그려서 설명해 보라"고 하셨어.

첨부 문서만 근거로 아래 4개를 만들어줘. 문서에 없는 숫자는 만들지 말고 "문서에 없음"이라고 써. 추정이면 "❌ 추정"이라고 표시해.

[1] 쉬운 말 정리 (초보용, 한국어)
- 한 문장 요약
- 2026-09-11 에 바뀐 것과 그 전의 차이 (표)
- 데이터를 어떻게 나누는지 (데이터셋 4개 장수 표 포함)
- 단계 순서 (C0 → C1 → 파일럿0 → validation 동결 → P → C 동결 → M1 → M2~M5) 와 각 단계가 "무엇을 결정하고 무엇을 결정하면 안 되는지"
- P 에서 후보 C 를 고르는 규칙 (A, B, A∪B, 12~23)
- 승자가 둘인 이유 (Full-grid winner vs Cross-validated winner)
- test 평가 방법 (슬라이딩 윈도우, 지표, 통계)
- 아직 안 정해진 것 목록
- 논문에 쓰면 안 되는 표현 5개

[2] 순서도
- mermaid flowchart 코드로. 상자마다 런 수를 적어. 파일럿 영역과 본실험 영역이 구분되게.
- 런 수 합계를 상자 밖에 한 줄로.

[3] 5분 발표 대본
- 전문용어는 처음 나올 때 한 번 풀어 쓰기. 단락마다 예상 소요 초.
- 마지막에 "이 설계가 답하려는 질문 4개".

[4] 교수님이 물어볼 만한 질문 10개와 답
- 각 답에 근거가 되는 문서의 절 번호나 결정 번호를 괄호로.

형식: 마크다운. 표는 마크다운 표. 전체 분량은 A4 5~6장 이내.
