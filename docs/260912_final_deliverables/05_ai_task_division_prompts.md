### ③-b Hamburger 논문 읽기
```
논문 "Is Attention Better Than Matrix Decomposition?" (Geng et al., ICLR 2021, Hamburger/HamNet) 을 읽고 설명해줘.
나는 데이터사이언스 초보야. 
1) 이 논문이 attention 대신 무엇을 쓰는지, 행렬분해(NMF)가 왜 "전역 문맥"을 잡을 수 있는지 그림으로 설명하듯 말해줘.
2) segmentation 헤더(LightHam)로 쓸 때 입력이 뭐고 출력이 뭔지.
3) attention 기반 헤더(OCRNet 같은 것)와 무엇이 다르고, 계산량은 어느 쪽이 적은지.
4) 작은 물체가 빽빽하게 겹쳐 있는 과실 이미지에서 이 방식이 유리할지 불리할지, 논문 근거가 있으면 근거와 함께.
5) 논문 Figure 중 발표에 한 장 가져간다면 어느 것인지.
```

### ①-b 설계 개념 질문 (막힐 때)
```
실험 설계에서 "20%를 파일럿으로 떼어 후보를 고르고, 80%에서 공통 holdout 한 번 + 선별된 후보만 5-fold 로 확증한다"는 구조를 초보에게 설명해줘.
특히 (a) 왜 파일럿 데이터를 본실험에 다시 쓰면 안 되는지, (b) "OOF(out-of-fold) 예측"이 뭔지, (c) "전체 5-fold CV" 라고 부르면 왜 틀리는지.
```
