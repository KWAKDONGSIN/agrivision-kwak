## 0. 전체 그림 — 무슨 상황이었나

- 0827 랩미팅에서 팀이 "우리 코드를 깃헙에 공개하자"고 정했다.
- 깃헙 = 코드를 인터넷에 올려 전 세계 누구나 볼 수 있게 하는 사이트. 논문을 낼 때 "코드도 여기 있습니다" 하고 같이 공개하는 게 요즘 관례다.
- 일을 4개로 나눴고, 곽동신 = ② 라이선스·저작권 정리 + 가중치는 링크만.
- 왜 이 일이 필요한가: **우리 코드가 100% 우리 것이 아니기 때문.** 남의 것을 우리 이름으로 인터넷에 올리면 저작권 문제가 생길 수 있다.

## 1. 우리 레포 안의 "남의 것" 3종류

1. **바탕 코드** — sithu 라는 개발자가 만든 세그멘테이션 코드를 가져다 우리가 고쳐 씀.
2. **가중치 파일(.pth)** — 남들이 대형 컴퓨터로 미리 학습시켜 둔 "완성된 두뇌" 숫자 파일. 우리는 이걸 출발점으로 쓴다 (사전학습).
3. **파이썬 패키지** — torch 등 22종. 설치해서 쓰는 도구들.

## 3. 실제로 한 일 — 순서대로

### 3-1. 목록 만들고 하나하나 원문 확인
- 바탕 코드 sithu → **MIT** ✅
- 우리가 추가한 헤더들의 출처 레포: Mask2Former **MIT** · BiRefNet **MIT** · LightHam(SegNeXt) **Apache-2.0**(고지 필요) · **CCASeg ❌ 라이선스 없음** ← 문제 ②
- 가중치 7개: ResNet·ConvNeXt·Swin·PVTv2·UniFormer = 허용형 / **MiT-B2·SegFormer·MambaVision = NVIDIA NC**(우리는 연구라 OK)
- 패키지 22종: 전부 허용형(BSD/MIT/Apache) ✅

### 3-2. 가중치는 파일 대신 "링크만" (교수님 강조)
- 이유: 3.3GB로 너무 크고, 남의 파일을 우리가 다시 배포하는 셈이 되기 때문.
- 그래서 `WEIGHTS.md` = "이 가중치는 여기서 받으세요" 주소표를 만들었다.
- `.gitignore`(= 깃헙에 올리지 말 것 목록) 점검 → `*.pth` 패턴이 빠져 있는 구멍 발견 → 7줄 추가로 막음.

### 3-3. 파일 4종 초안 작성 → 브랜치에 커밋
- `LICENSE`: "우리 수정분은 MIT" 선언 + 저자 표기(main.tex 285~295행 그대로)
- `NOTICE.md`: "이 안에 남의 코드가 이렇게 들어 있고 조건은 이렇다" 고지문
- `WEIGHTS.md`: 가중치 다운로드 안내표
- `licenses/`: 원문 라이선스 사본 3개
- **브랜치 `kwak/license-0830`** 에 커밋 = 원본(main)은 안 건드리고 복사 작업대에서 작업. 팀 확인 후 합치면(병합) 끝.

### 3-4. "가중치가 진짜 공식 파일인가" 지문 대조 → 문제 ① 발견
- sha256 = 파일의 지문. 한 글자만 달라도 지문이 바뀐다.
- Swin-T·PVTv2-B2: 공식 파일과 지문 일치 ✅ / ResNet-50: 파일명 해시 일치 ✅
- **ConvNeXt: 어떤 공식 1k 파일과도 안 맞음** → 지문 대신 내용물(텐서 숫자값)을 직접 대조 → **timm 의 22k 사전학습본과 180/180 완전 동일**
- 2026-08-31 로컬 클로드가 "sithu 변환 1k 사본 아니냐" 반론 → 다른 방법(부분 다운로드 텐서 대조)으로 재검증 → **22k 확정** (1k본과는 값이 다름. 키 이름 변환은 숫자값을 못 바꾸므로 반론 기각)
- 왜 문제인가: 다른 백본은 사진 128만 장으로 공부, ConvNeXt 만 1,400만 장. 0722 실험 1등이 "구조 덕인지 공부량 덕인지" 구분 불가 → 논문 비교의 공정성 문제. **교수님 결정 필요** (그대로 명시 vs 1k 로 재실험)
