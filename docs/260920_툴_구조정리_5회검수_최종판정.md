## 4. 의도적으로 달라진 것

사용자가 허용한 데이터 소실 예외 한 건을 수정했습니다. 비어 있지 않은 요청의 상자가 전부 무효일 때 기존 코드는 빈 목록처럼 해석해 기존 상자·확정을 지웠습니다. 후보는400으로 거절하고 파일을 그대로 둡니다. 명시적 빈 목록 되돌리기와 유효 저장은 유지합니다.

시험용 ff.py는 LABELTOOL_URL을 주지 않으면 geckodriver 실행 전에 멈춥니다. 실서버5111로 자동 접속하던 기본값 위험을 없앴습니다. 이 보호도 후보에만 있습니다.

## 5. 못 한 것과 운영 상태

- 실제 긴 함수3개를 남겼습니다. 동작 보존을 우선한 예외 목록입니다.
- JS window 연결5개, UI 역방향호출, 단축키 표와 분기 중복이 남았습니다. 전역이 정확히3개뿐이라고 주장하지 않습니다.
- Any를 포함하며 전체 정적 타입 검사를 수행한 것은 아닙니다.
- 같은 사진 동시편집의 오래된 저장을 거절하는 revision 기능, 변경 이력, 재학습 고리는 없습니다.
- 정적6칸 불일치 때문에 운영코드는 전환하지 않았습니다. 후보 보호수정이 운영에도 적용됐다고 생각하면 안 됩니다.
- 이전 Claude가 인계 전 운영 디스크를 이미 분리판으로 바꿔 놓았으며 Python 프로세스는00:04 판을 실행 중입니다. Codex는 이 상태를 임의로 덮거나 재시작하지 않았습니다.
