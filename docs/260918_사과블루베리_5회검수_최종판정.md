   **±10~15%p** 가 붙습니다. 흔들리지 않는 숫자가 필요하면 **간격 솎기**를 쓰십시오.
4. **확인 범위 밖에 254쌍이 아직 아무도 안 봤습니다**(현장 간격 25~60 · dataset 60).
