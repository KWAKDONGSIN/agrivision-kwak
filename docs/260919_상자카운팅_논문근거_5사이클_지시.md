# 1. 만들 것 — «상자 + 개수 세기» 가 한 흐름으로
지금 상태(14:00): 툴에 상자 모드(`/box` 전용 화면, 팀원 상자 자동 초벌)와 번호(인스턴스) 편집이 있다. **개수(카운팅)는 화면에 «상자 N개» 로만 보이고, 사람이 «이 사진의 과일 수는 N 이 맞다» 고 확정하거나 내보내는 길이 없다.** 이것을 채운다.

1. **사진마다 «개수» 칸** — 하단 줄 또는 오른쪽 칸에 `개수: 상자 N · 번호 M · 팀원(박성문) K` 를 늘 보이게. 값이 서로 다르면 표시(예: 상자 16 ≠ 번호 15).
2. **사람 확정 개수** — 상자 확정(Enter/저장)과 번호 확정이 곧 개수 확정이 되게 한다(별도 입력 없이). 다만 «상자·번호 없이 개수만 셀 때» 를 위해 숫자 직접 입력 칸(선택)을 둘지는 사이클 1 이 결정(yagni 원칙; 녹취 0908 «AI 초벌 + 사람이 맞다/틀리다» 에 맞는 최소 형태).
3. **개수 내보내기** — «데이터 정리» 탭에 `counts.csv`(stem, n_boxes, n_instances, n_team_park, n_team_im, n_human, human_source(boxes|instances), confirmed_by, confirmed_at) 를 상자 YOLO 내보내기와 같은 자리에서. 기본 «사람 확정만».
4. **통합 데이터셋에 개수 칸** — `tools/build_merged_dataset.py` manifest 에 `n_boxes, n_instances, n_count_human, count_source` 를 추가(툴 확정을 읽음). 0920·0921 재빌드에 그대로 들어가게.
5. **상자 정의 문서화** — 상자 = 마스크(또는 번호)의 보이는 영역을 꼭 감싸는 축정렬 최소 상자(modal, COCO 관례). amodal 여부는 교수님 질문 #1 미결이므로 «지금은 modal» 을 README·help 에 명시.

# 2. 논문 근거 대조 — «모든 것이 논문을 기반으로 돼 있나»
자료: `platform/01_references/INDEX.md`(PDF 143편, `pdf/<citekey>.pdf`) · `bib/260812_counting.bib` · `05_ai_dialogues/근거문서/260812_카운팅방법_근거_확정본.md`(Bargoti 2017 · Zabawa 2020 · Häni 2020 · Kornilov) · `260813_사진처리_전과정과_논문근거.md` · `260812_디텍션논문_근거조사.md` · `kds0206/연구실 블루베리/03_참고논문_리뷰/`.

대조 항목(최소):
- 카운팅 = 마스크→거리변환+워터셰드→개체→개수 (Bargoti 2017, Zabawa 2020, Kornilov) — 박성문 도구·툴 초벌(`boxes_of`, `instance_split`)이 이것을 따르는가, 포도는 CC 만(송이) 근거.
- 상자 = 개체별 tight box, 클래스 0 과실/1 송이/2 기타 (COCO lin2014coco, MinneApple 상자 정의, WGISD/blekos2023grape 포도 송이 단위).
- 라벨 범위 = 전경 나무의 과실만, 땅·배경 나무 제외 (Häni 2020 원문 — 우리 flag «땅에 떨어진 과실» 규칙과 일치하는가).
- 개수 평가 지표 = MAE/RMSE/R²·계수 정확도(Häni 2020 카운팅 절, Zabawa 94.0%/85.6%, Bargoti F1 0.858) — 내보낸 counts.csv 로 계산 가능한 형태인가(GT 있는 사과·복숭아).
- 중복·근접 프레임 제거와 촬영 단위 분할(GroupKFold) — 데이터 누수 근거(Häni 2020 시퀀스 분할, demsar2006 다중 데이터셋 비교, 기타 INDEX 에 있는 벤치마크 논문).
- 2MP 비율 유지 리사이즈·마스크 NEAREST(`260813_사진처리…` 의 근거 재확인).
- 툴의 «AI 초벌 → 사람 확정» 흐름(human-in-the-loop 라벨링 근거가 INDEX 에 있으면 인용, 없으면 «근거 없음 — 교수님 지시(0908 녹취)» 로 정직하게 표기).
규칙: **근거가 없으면 지어내지 말고 «근거 없음» 으로 적는다.** 원문 인용은 반드시 `pdftotext` 로 PDF 에서 글자 그대로 확인한 것만. «사후 정당화» 라는 260813 문서의 경고 문장을 대조표 머리에 그대로 옮긴다. 논문과 어긋나는 것이 나오면 **고친다**(코드·문서) — 단, 데이터셋 파일을 바꾸는 조치는 0920 재빌드로 미루고 목록만 남긴다.
