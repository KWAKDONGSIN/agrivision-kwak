# 열매 번호(인스턴스) 라벨 — 실제 현황과 선택지

카톡(09-23 16:59 박성문 «인스턴스로는 가망 없다, 데이터셋 다시 찾아야») 에 대한 확인 결과다. 숫자는 전부 서버에서 직접 센 값이다.

## 1. 결론

**데이터셋을 새로 찾을 필요는 거의 없다.** 네 과일 중 세 과일은 원본 데이터에 열매별 정답이 이미 있었다(우리가 안 쓰고 있었을 뿐).
블루베리만 정답 번호가 없고, 이것은 원 저자에게 요청하거나 툴(모델 초벌 + ✨ 클릭)로 채운다.

## 3. 툴에서 바로 쓰는 법 (2026-09-23 반영)

- 포도·복숭아: 파일 → **«번호만 원본 정답으로 나누기 (칠한 모양 그대로)»**. 칠한 모양은 그대로 두고 번호만 원본 정답으로 바꾼다. 원본에 없는 큰 덩어리(검수에서 더한 열매)는 새 번호, 가장자리 조각은 옆 열매에 붙는다.
  실측: 포도 사진 0 = 칠한 덩어리 15개 → 정답 송이 8개 · 복숭아 210629-t1-01 = 11(원본) + 1(검수에서 더한 것) = 12.
- 블루베리·사과: **«모델 초벌: 빠진 열매만 더하기»**(노란 동그라미) → 틀린 것 지우기 → 모자란 건 ✨ 클릭.

## 4-2. 초벌 개선 방법 비교 (원본 정답 대비, 과일마다 최대 120장)

| 방법 | 결과 |
|---|---|
| A 기본(지금 초벌) | F1 사과 0.83 · 포도 0.75 · 복숭아 0.73 — **가장 좋음** |
| B TTA | A 와 값이 똑같음 — 이 프로그램은 분할 모델에서 TTA 를 적용하지 않는 것으로 보임(효과 확인 못 함) |
