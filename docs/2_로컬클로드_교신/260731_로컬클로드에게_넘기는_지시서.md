## 1. 🔴 로컬 클로드가 할 일 (우선순위 순)

### ① Overleaf 에 논문 초안 올리고 **컴파일이 되는지 확인** ← 제일 중요

서버에는 LaTeX 컴파일러가 없어서 **PDF가 나오는지 한 번도 확인하지 못했습니다.**
이게 가장 큰 미검증 항목입니다.

**필요한 파일** — 곽동신 님이 서버에서 내려받아 주십니다:
```
논문초안_오버리프.zip
 ├ main.tex          ← 본문 (팀원 초안 기준 + 서버 클로드가 실측값 채움)
 ├ references.bib    ← 참고문헌 22건
 └ figures/          ← 포도 실험 그림 4장
```

**순서**
1. Overleaf 접속 (교수님이 이미 프로젝트에 초대해 두셨습니다)
2. ⚠️ **먼저 확인**: 프로젝트에 `sn-jnl.cls` 가 있는지.
   - 없으면 → `New Project → Templates` 에서 **Springer Nature LaTeX Template** 으로
     새 프로젝트를 만들고, 거기에 우리 파일을 덮어씁니다.
   - 이걸 안 하면 `File 'sn-jnl.cls' not found` 에러가 납니다. **정상입니다, 당황하지 마세요.**
3. `main.tex`, `references.bib`, `figures/` 업로드
4. **Recompile** 눌러서 PDF가 나오는지 확인
5. 🔴 **에러가 나면 그 메시지를 곽동신 님께 그대로 보여주세요.** 서버 클로드가 고칩니다.

**주의 — 남의 작업을 지우지 말 것**
- 프로젝트에 이미 `main.tex` 가 있으면 **덮어쓰기 전에 기존 파일을 `main_old.tex` 로
  이름을 바꿔 두세요.** 팀원(최인훈 님)이 Method 모델선정 파트를 작업 중입니다.
- 최인훈 님 담당 절(`\subsection{Segmentation head selection}`,
  `\subsection{Backbone selection and capacity control}`)은 **건드리지 마세요.**

### ② NinePeach(복숭아) 데이터셋 내려받기 — 서버가 못 하는 일

Google Drive 링크라 서버에서 `curl` 로 못 받습니다. 브라우저가 있어야 합니다.
- 받은 뒤 **zip 1개로 묶어서** VS Code Remote 로 서버 `incoming/` 에 올리면 됩니다.

  zip 1개 방식은 2/2 성공했습니다. 20GB 넘으면 분할하세요.

### ③ 참고문헌 서지사항 확인 (브라우저 검색 필요)

## 3. 논문 초안에 대해 알아야 할 배경

### 이 파일이 어디서 왔나

1. 교수님이 미팅에서 AI에게 프롬프트를 불러주심 → `LaTaX초안.txt`
2. AI가 초안 생성 → **팀원이 MinneApple 기준으로 다듬음** → `main tex LaTax 예시로 써준거.txt` (732줄)
3. 서버 클로드가 거기에 **실제 측정값만** 채워 넣음 → 지금의 `main.tex`

**팀원 초안의 구조·문장은 그대로 뒀습니다.** 서버 클로드가 손댄 곳은 `[KDS]` 로 표시돼 있습니다.
