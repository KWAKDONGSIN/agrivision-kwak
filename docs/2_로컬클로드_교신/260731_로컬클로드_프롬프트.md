# 네가 할 일 (우선순위 순)

## ① 제일 중요 — Overleaf에 논문 올리고 **컴파일이 되는지 확인**

첨부한 `논문초안_오버리프.zip` 안에 이게 들어 있어.
  main.tex        본문
  references.bib  참고문헌 22건
  figures/        포도 실험 그림 4장

**서버에는 LaTeX 컴파일러가 없어서 PDF가 나오는지 한 번도 확인을 못 했어.**
이게 지금 가장 큰 미검증 항목이야. 순서는 이렇게 해줘.

1. Overleaf(overleaf.com) 접속. 안홍렬 교수님이 이미 프로젝트에 나를 초대해 두셨어.
2. 🔴 **먼저 확인할 것**: 그 프로젝트에 `sn-jnl.cls` 파일이 있는지 봐줘.
   - 없으면 → `New Project → Templates` 에서 **"Springer Nature LaTeX Template"** 을
     검색해 새 프로젝트로 만들고, 거기에 우리 파일을 넣어. 그 템플릿에 딸려오는
     `sn-jnl.cls` 가 있어야 컴파일이 돼.
   - 이걸 안 하면 `File 'sn-jnl.cls' not found` 에러가 나. **정상이니까 당황하지 마.**
3. `main.tex`, `references.bib`, `figures/` 를 업로드해.
4. 🔴 **덮어쓰기 주의**: 프로젝트에 이미 `main.tex` 가 있으면, 덮어쓰기 전에
   기존 파일 이름을 `main_old.tex` 로 바꿔서 **남겨둬**. 팀원 최인훈 님이 작업 중이야.
   그리고 덮어쓰기 전에 **기존 파일과 우리 파일이 어디가 다른지 나한테 먼저 알려줘.**
5. 초록색 **Recompile** 을 눌러서 PDF가 나오는지 확인해줘.
6. 🔴 **에러가 나면 그 메시지를 그대로 나한테 보여줘.** 서버 클로드가 고칠 거야.
   네가 임의로 main.tex 내용을 고쳐서 에러를 없애려고 하지 마.

# 하면 안 되는 것

- `연구실 블루베리` 폴더의 파일을 **지우거나 옮기지 마.**
  이건 서버에 올린 60.87GB의 원본이야. 2026-07-30에 이 폴더를 지워서
  심볼릭 링크 49,212개가 끊긴 사고가 있었어.
- 논문에 들어갈 **숫자를 지어내지 마.** 실험 결과는 서버에서만 나와.
- 최인훈 님 담당 절은 건드리지 마:
  `\subsection{Segmentation head selection}`
  `\subsection{Backbone selection and capacity control}`
- 학습을 로컬에서 돌리려고 하지 마. GPU는 서버에 있어.
