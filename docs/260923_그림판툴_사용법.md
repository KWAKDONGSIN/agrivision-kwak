# 라벨 그림판 사용법 (한 장)

주소: `http://<서버주소>:5111/` (예전 주소 그대로). 옛 툴은 `/old`.
이 문서는 09-26 기준 화면과 코드에 맞춰 고쳤습니다.

## 규칙 하나
**색 하나 = 열매 하나.** 같은 열매는 같은 색으로 칠합니다.
잎에 가려 두 조각이 된 열매도 같은 색으로 칠하면 **상자는 하나**로 저장됩니다.
사과·포도는 규칙 일부가 아직 **미정**(교수님 답 대기)입니다. 그 과일을 고르면 메뉴 아래 노란 줄에 한 줄로 나옵니다.

## 도구 (왼쪽 상자)
| 도구 | 키 | 하는 일 |
|---|---|---|
| 붓 | B | 지금 색으로 칠하기 |
| 지우개 | E | 끌어서 지우기(마스크·번호 같이) |
| 채우기통 | F | 칠해진 덩어리를 누르면 번호가 붙음. 오른쪽 클릭 = 그 덩어리 통째로 지우기 |
| 올가미 | L | 테두리를 따라 그리면 안이 칠해짐. 오른쪽 클릭으로 그리면 안쪽이 지워짐 |
| 스포이트 | I | 누른 열매의 색을 집고, 집으면 자동으로 붓으로 바뀜. 번호 없는 회색은 집을 수 없음 |
| 돋보기 | Z | 왼쪽 클릭 = 확대, 오른쪽 클릭 = 축소 |
| 손 | H | 끌어서 옮기기 |
| 새 번호 | N | 다음 번호 색을 고름 |
| ✨ 클릭 칠하기 | S | 열매를 누르면 AI(SAM)가 모양대로 칠함. 같은 자리를 다시 누를 때마다 후보 모양이 돌아가며 바뀜(후보 수는 사진마다 다름). **끌어서 네모** = 그 안의 열매 하나. **Shift+클릭** = 방금 칠한 것에서 그 부분 떼어 내기. 이미 번호가 있는 열매를 누르면 «먼저 오른쪽 클릭으로 지우라» 고 알려 줌 |
| 비슷한 열매 찾기 | G | 지금 색 열매와 크기·둥근 정도·색이 비슷한 것을 사진 전체에서 찾아 **노란 테두리**로 보임. 틀린 것은 눌러서 빼고(빨간 테두리) **Enter = 모두 받기**(남은 후보마다 새 번호), **Esc = 취소**. 이미 칠한 곳은 건드리지 않음 |

**오른쪽 클릭 = 지우기**는 지우개·스포이트·손·돋보기를 뺀 모든 칠하기 도구에서 됩니다. 휠 = 확대·축소, 스페이스+끌기 = 옮기기는 어떤 도구에서든 됩니다.

옵션 (도구를 고르면 왼쪽 아래에 나옴)
- 채우기통: «누를 때마다 새 번호»(열매 세기) / «지금 색 그대로»(가려진 조각 합치기).
- 붓·올가미·✨: «다른 열매 위에는 안 칠함»(기본 켜짐) — 붙은 열매를 칠할 때 옆 열매를 덮지 않습니다.
- 붓 굵기: 4 / 8 / 16 / 32 / 64 단추, 또는 `[` `]` 키.

## 단축키 한눈에
| 키 | 하는 일 |
|---|---|
| Ctrl+S | 저장 |
| Ctrl+Enter | 저장하고 다음 사진 |
| A · D 또는 ← · → | 이전 · 다음 사진 |
| Ctrl+Z | 되돌리기 |
| Ctrl+Y 또는 Ctrl+Shift+Z | 다시 하기 |
| `+` `-` | 확대 · 축소 |
| `1` · `0` | 100% · 사진 전체를 가운데로 |
| V | 원본 보기(색 숨기기/보이기) |
| T | 번호 글자 숨기기/보이기 |
| C | 512 크롭 네모 보이기/숨기기 (AI 가 한 번에 보는 크기, 빨간색) |
| Esc | 메뉴 닫기 · 올가미/✨ 끌기/비슷한 열매 후보 취소 |

저장 중에는 되돌리기·다시 하기·새 번호·모두 받기·모델 초벌·번호 나누기·전부 지우기가 저장이 끝날 때까지 기다립니다.
저장하는 도중에 칠한 것은 «저장 안 됨» 으로 남으니 한 번 더 저장하세요.

## 화면 위쪽
- **과일 · 사진 선택**, **이름 찾기**(Enter), **안 한 것만**(사람이 아직 저장 안 한 사진만).
- **표본 100장만** — 카운팅 벤치마크용. 과일마다 늘 같은 100장(이름으로 정해짐)이라, 누가 열어도 목록이 같습니다.
- **순서: 이름 순 / 헷갈리는 순** — 헷갈리는 순은 사람이 아직 확정 안 한 사진을 앞에 두고, 초벌 모델이 확신한 열매 수와 원 라벨 열매 수의 차이가 큰 사진부터 보여 줍니다.
- **🔁 닮은 사진** — 지금 사진이 거의 같은 사진(연속 스냅샷) 묶음에 있으면 나타납니다. 눌러서 묶음을 보고 «대표만 남기기» 를 누르면 대표가 아닌 사진 중 아직 확정 안 한 것이 «빼기» 로 처리됩니다.
- 안 저장한 칠이 있는 사진은 «안 한 것만»·정렬·찾기를 바꿔도 목록에서 빠지지 않고, 칠이 사라지지도 않습니다.

## 화면 아래 상태줄
- 왼쪽 글줄 = 방금 한 일·경고. 두 줄이 되거나 잘리면 마우스를 올리면 전체가 나옵니다.
- **진행 N/전체** — 이 과일에서 저장(✓)하거나 뺀(✕) 사진 수. 표본 100장을 켜면 표본 중 저장한 수.
- **재학습 준비** — 사람이 확정한 사진 수와 마지막으로 데이터셋을 내보낸 시각, «내보내기 ↗»(옛 툴의 데이터 정리 탭으로 감).
- 작업자 이름은 눌러서 바꿉니다.
- 제목줄에 «저장 안 됨» 이 보이면 아직 저장하지 않은 칠이 있다는 뜻입니다.

## 원본 보기
- 위쪽 **«👁 원본 보기»** 단추(또는 V) = 색·번호를 숨기고 사진만. 다시 누르면 색이 돌아옴.
- **` 키(1 왼쪽)를 누르고 있는 동안만** 사진만 보임 — 칠한 것과 사진을 빠르게 비교할 때.
- 보기 메뉴의 «색 진하기» 슬라이더로 색의 진하기를 바꿉니다.
- 확대해도 사진은 부드럽게 보이고, 색 칸만 또렷하게 보입니다. 오른쪽 아래 «－ / % / ＋ / ⤢ 가운데로» 단추로도 확대·축소합니다.

## 저장 뒤·✨ 뒤에 나오는 경고 (저장을 막지는 않음)
- **빨간 점선 동그라미** — 저장 뒤 넓이·둥근 정도·다른 열매와 맞닿음·떨어진 조각이 다른 열매보다 튀는 번호. 열매가 아닐 수도 있으니 한 번 봐 달라는 표시일 뿐입니다.
- **✨ 결과 경고(빨간 글씨)** — 결과가 잎·가지처럼 길쭉하거나, 동그랗지 않거나, 사진에 비해 너무 크면 알림 줄에 알립니다. 칠은 그대로 되어 있으니 틀리면 Ctrl+Z.

## 자주 하는 일
- 라벨 없는 열매가 많은 사진: 파일 → «모델 초벌: 빠진 열매만 더하기» 로 모델이 찾은 열매를 얹고(노란 동그라미), 틀린 것만 지운 뒤 저장. 모자란 건 ✨ 로 하나씩 누르거나, 열매 하나를 칠하고 G 로 비슷한 것을 한꺼번에 받음.
  - 초벌 = 우리 라벨로 학습한 YOLO11m-seg 가 네 과일 전체 4,727장에 만든 예측. 정확도 숫자는 근거 파일을 못 찾아 이 문서에서는 뺐습니다.
- 번호 붙이기: F → 칠해진 열매를 차례로 클릭.
- 빠진 열매 넣기: N → L 로 테두리 그리기(또는 B 로 칠하기).
- 잘못 칠한 것 지우기: F 로 오른쪽 클릭(덩어리째) 또는 E.
- 저장: Ctrl+S — 마스크·번호·상자가 한 번에 저장되고 «사람이 확인함» 으로 남습니다.
- 흐리거나 너무 가까운 사진: 파일 → «이 사진 빼기» (실수면 «빼기 취소»).
- 회색: 원본에 칠해져 있지만 번호가 없는 곳. 채우기통으로 누르면 번호가 붙습니다.
- 파일 메뉴 나머지: «모델 초벌로 전부 바꾸기», «번호만 원본 정답/모델 초벌로 나누기»(칠한 모양은 그대로 두고 번호만), «원본 다시 불러오기»(저장 전까지는 안전).
- 편집 메뉴 «전부 지우기» 는 이 사진의 칠을 모두 지웁니다(저장 전이면 Ctrl+Z 로 되돌림).
