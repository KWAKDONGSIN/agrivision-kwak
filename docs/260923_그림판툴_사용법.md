# 라벨 그림판 사용법 (한 장)

주소: `http://<서버주소>:5111/` (예전 주소 그대로). 옛 툴은 `/old`.

## 규칙 하나
**색 하나 = 열매 하나.** 같은 열매는 같은 색으로 칠합니다.
잎에 가려 두 조각이 된 열매도 같은 색으로 칠하면 **상자는 하나**로 저장됩니다.

## 도구 (왼쪽 상자)
| 도구 | 키 | 하는 일 |
|---|---|---|
| 붓 | B | 지금 색으로 칠하기. 오른쪽 클릭 = 지우기 |
| 지우개 | E | 끌어서 지우기(마스크·번호 같이) |
| 채우기통 | F | 칠해진 덩어리를 누르면 번호가 붙음. 오른쪽 클릭 = 그 덩어리 통째로 지우기 |
| 올가미 | L | 테두리를 따라 그리면 안이 칠해짐 |
| 스포이트 | I | 누른 열매의 색을 집음 |
| 돋보기 · 손 | Z · H | 확대·옮기기 (휠 = 확대, 스페이스+끌기 = 옮기기) |
| 새 번호 | N | 다음 번호 색을 고름 |
| ✨ 클릭 칠하기 | S | 열매를 누르면 AI(SAM)가 모양대로 칠함. 같은 자리를 다시 누르면 다른 모양(알 하나 → 크게 → 송이). **끌어서 네모** = 그 안의 열매 하나. **Shift+클릭** = 방금 칠한 것에서 그 부분 떼어 내기. 오른쪽 = 덩어리 지우기 |

채우기통 옵션: «누를 때마다 새 번호»(열매 세기) / «지금 색 그대로»(가려진 조각 합치기).
붓 옵션: «다른 열매 위에는 안 칠함»(기본 켜짐) — 붙은 열매를 칠할 때 옆 열매를 덮지 않습니다.

## 자주 하는 일
- 라벨 없는 열매가 많은 사진: 파일 → «모델 초벌: 빠진 열매만 더하기» 로 모델이 찾은 열매를 얹고(노란 동그라미), 틀린 것만 지운 뒤 저장. 모자란 건 ✨ 로 하나씩 누름.
  - 초벌 = 우리 라벨 4,726장으로 학습한 YOLO11m-seg(마스크 mAP50 0.84)가 네 과일 전체 4,727장에 만든 예측. 표본 60장 기준 원 라벨 중 초벌이 찾은 비율: 사과 93% · 블루베리 86% · 포도 80% · 복숭아 97%.
- 번호 붙이기: F → 칠해진 열매를 차례로 클릭.
- 빠진 열매 넣기: N → L 로 테두리 그리기(또는 B 로 칠하기).
- 잘못 칠한 것 지우기: F 로 오른쪽 클릭(덩어리째) 또는 E.
- 저장: Ctrl+S — 마스크·번호·상자가 한 번에 저장되고 «사람이 확인함» 으로 남습니다.
- 흐리거나 너무 가까운 사진: 파일 → «이 사진 빼기».
- 회색: 원본에 칠해져 있지만 번호가 없는 곳. 채우기통으로 누르면 번호가 붙습니다.

## 바뀐 것
- AI 판정(AI 제안 마스크·문제 표시·의심 목록·점수)은 화면에서 모두 뺐습니다. 파일은 지우지 않았습니다.
- 목록의 ✓ 는 사람이 저장한 사진, ✕ 는 사람이 뺀 사진뿐입니다.
- 저장 위치·형식은 옛 툴과 같아서 통합 데이터셋 빌드는 그대로 씁니다.
