==============================================
꼭 알아두실 것 4가지
==============================================

1) 블루베리는 1,195장 전량 · 7:1:2 로 새로 나눴습니다 (2026-08-08).
   0806 미팅에서 뺐던 4K 128장(Camera 4)을 다시 넣어 전량을 씁니다.
   → 예전 분할은 7:1:2 가 아니라 약 67:17:17 이었어서 팀 규칙에 맞춰 다시 떴습니다.
   → 폴드 구성이 바뀌었으니 기존 블루베리 192런 결과와 직접 비교 불가. 재학습 필요합니다.
   → ※ 블루베리만 '영상 단위'로 뽑습니다. 파일명이 Camera 3 Video (11)_181.png 처럼
     '어느 영상의 몇 번째 프레임' 이라, 한 장씩 랜덤으로 뽑으면 같은 영상이
     학습과 시험에 동시에 들어가 점수가 부풀려집니다. 영상 288개를 통째로 갈랐고,
     같은 영상이 train/val/test 에 걸치는 경우는 6폴드 전부 0건입니다.

2) 사과는 720x1280 -> 1080x1920 으로 1.5배 키운 겁니다.
   사진은 MinneApple 원본 그대로이고 크기만 키웠습니다. 논문 Method 에 명시 필요합니다.

3) 포도는 토이 100장 -> 전체 2,502장으로 교체했습니다.
   기존 포도 결과(54조합)는 이 데이터와 비교 불가입니다. 데이터가 25배라 학습 시간도 늘어납니다.

4) 사과 cv1~cv5 는 사진 단위 무작위 분할이라, 동영상 앞뒤 프레임이
   학습/시험에 갈라져 들어갈 수 있습니다(점수가 실제보다 높게 나올 수 있음).
   비교하려면 single(2015학습/2016시험) 로도 한 번 돌려보시는 걸 권합니다.

==============================================
복사 안 하셔도 됩니다 (중요)
==============================================

이 폴더는 lab 그룹 전원이 읽을 수 있게 열려 있습니다.
그냥 yaml 의 ROOT 에 위 경로를 그대로 적으시면 바로 학습됩니다.
→ 디스크도 안 쓰고, 제가 데이터를 고치면 자동으로 반영됩니다.

굳이 내 폴더로 복사하셔야 한다면:

  (O) cp -a  /data/project/2026summer/kds0206/datasets_resized_2mp 내폴더/     ← 약 13GB. 이걸 쓰세요
  (X) cp -rL /data/project/2026summer/kds0206/datasets_resized_2mp 내폴더/     ← 약 129GB 로 불어납니다. 쓰지 마세요

  · splits 안이 전부 바로가기(심볼릭 링크)라 -L 을 붙이면 같은 사진이
    폴드마다 실파일로 복사됩니다(86,020개). -a 는 바로가기를 그대로 둡니다.
  · 바로가기가 상대경로라 폴더째 옮겨도 안 깨집니다.

  폴드 하나만 따로 떼고 싶으시면 그때만 -L 을 쓰세요:
    cp -rL /data/project/2026summer/kds0206/datasets_resized_2mp/splits/grape/cv1 내폴더/
