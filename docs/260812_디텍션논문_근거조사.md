## 0. 왜 이 문서를 만들었나

팀 카톡으로 받은 요청:

> "디텍션 논문들 찾아보면서 저 방법으로 하는지 확인 한 번 해주세요.
>  저희가 이렇게 진행한 증거가 있어야 해요."

여기서 «저 방법» = 2026-08-10 에 만든 개수 세는 방법.
**세그멘테이션 마스크 → 거리변환(distance transform) → 워터셰드(watershed) → 개체 하나씩 분리 → 개수 셈.**
(모델을 새로 학습시키지 않고, 이미 있는 라벨을 계산으로 처리)

## 1. 결론 먼저 (3줄)

1. **있습니다. 그것도 사과 과수원 논문에 정확히 같은 방법이 있습니다.**
   Bargoti & Underwood (2017) 는 픽셀 단위 세그멘테이션 결과를 **워터셰드로 후처리해서
   사과를 «한 알씩» 검출·계수**했고, 그 방식이 자기들 실험에서 **가장 성적이 좋았습니다(F1 0.858)**.
2. **«붙은 열매를 그냥 덩어리로 세면 안 된다»는 것도 논문에 근거가 있습니다.**
   포도 논문 Zabawa et al. (2020) 은 연결요소(connected components)로 세기 위해
   일부러 «edge(경계선)» 클래스를 하나 더 만들었습니다. 그렇게 안 하면 **붙어 있는 알이
   하나로 합쳐지기 때문**입니다. 우리가 실측한 «덩어리로 세면 18.2% 과소계수»와 같은 이야기입니다.
3. **«디텍션을 꼭 돌려야 하는 것은 아닙니다.»**
   디텍션 모델은 개수를 세는 여러 수단 중 하나이고, 마스크만 있을 때는
   워터셰드/연결요소 후처리가 **표준적인 대안**입니다. 다만 우리는 한 걸음 더 갔습니다 —
   **사과 정답으로 우리 방법의 오차를 실제로 쟀습니다(+0.7%).** 위 논문들도 이렇게 자기 검증을 합니다.

## 2. 근거 논문 (원문 PDF를 직접 열어 확인한 것)

### ① Bargoti & Underwood (2017) — 가장 중요한 근거

| 항목 | 내용 |
|---|---|
| 제목 | Image Segmentation for Fruit Detection and Yield Estimation in Apple Orchards |
| 저자 | Suchet Bargoti, James P. Underwood (Australian Centre for Field Robotics, Univ. of Sydney) |
| 출처 | Journal of Field Robotics, 2017 / preprint arXiv:1610.08120 |
| 대상 | 호주 상업용 **사과 과수원** |

**원문 인용 (초록)**

> "The pixel-wise fruit segmentation output is processed using the Watershed Segmentation (WS)
> and Circular Hough Transform (CHT) algorithms to detect and count individual fruits."

> "The WS algorithm produced the best apple detection and counting results,
> with a detection F1-score of 0.858."

**원문 인용 (본문, 검출 단계)**

> "fruits are often clustered together and appear occluded in the image data due to other fruits
> and foliage. A suitable fruit detection algorithm needs to be able to **separate individual fruits
> in clusters** and also **connect disjoint regions of the same fruit, formed due to occlusions**."

> "The WS algorithm is used for separating connected objects in an image where each object is
> characterised by a local maximum and a contour leading to its boundary. For a segmented fruit
> image, this contour is evaluated by **computing distances of individual fruit pixels to the nearest
> background pixel**, resulting in **a local maximum that is typically situated around the centre of
> each fruit**."

**우리 방법과의 대응 — 문장 단위로 그대로 겹칩니다**

| 논문 | 우리 (tools/instance_split.py) |
|---|---|
| 픽셀 단위 세그멘테이션 결과를 후처리 | 이진 마스크를 후처리 |
| «각 열매 픽셀에서 가장 가까운 배경까지의 거리»를 계산 | 거리변환 (distance transform) |
| 그 거리의 «국소 최대값 = 열매 중심» | 봉우리 = 열매 중심 |
| 워터셰드로 붙은 객체 분리 | 워터셰드로 분리 |
| 목적 = 개별 열매 검출·계수 | 목적 = 장당 개체 수 |

🔴 **두 번째 인용문의 뒷부분이 우리 포도 문제의 근거이기도 합니다.**
«가려져서 한 열매가 여러 조각으로 끊긴 것을 다시 이어 붙여야 한다»가 논문에 적혀 있습니다.
우리가 포도에서 겪은 «잎에 가려 한 송이가 여러 조각 → 연결요소가 15,102개로 부풀림»이
바로 이 문제이고, 그래서 포도는 **정답 인스턴스 마스크(9,832송이)** 를 쓰기로 한 것입니다.

### ② Zabawa et al. (2020) — 「덩어리로 세면 안 된다」의 근거

| 항목 | 내용 |
|---|---|
| 제목 | Counting of Grapevine Berries in Images via Semantic Segmentation using Convolutional Neural Networks |
| 저자 | Laura Zabawa, Anna Kicherer, Lasse Klingbeil, Reinhard Töpfer, Heiner Kuhlmann, Ribana Roscher (Bonn Univ. / Julius Kühn-Institut) |
| 출처 | arXiv:2004.14010 (2020) |
| 대상 | **포도 (grapevine berries)** |

**원문 인용 (초록)**

> "Our framework uses a convolutional neural network to detect single berries in images by
> performing a **semantic segmentation**. **Each berry is then counted with a connected component
> algorithm.**"

> "We achieve an accuracy for the berry detection of 94.0% in the VSP and 85.6% in the SMPH."

**원문 인용 (서론 — 왜 edge 클래스를 만들었나)**

> "To avoid a computationally intensive instance segmentation we reformulate a semantic
> segmentation task in a way that results in single object instances without object proposals.
> We define three classes, 'berry', 'edge' and 'background' so that **every single berry is separated
> from neighbouring berries by an edge** and can therefore be identified as a single instance.
> **There is no need to explicitly perform an instance segmentation.**"

> "The edge width is a crucial parameter to distinguish between single elements."

**이게 왜 우리 근거가 되나**

- 이 논문은 **«디텍션(인스턴스 세그멘테이션) 모델을 안 쓰고» 세그멘테이션 + 후처리로 개수를 셉니다.**
  «값비싼 인스턴스 세그멘테이션을 피하려고»라고 이유까지 명시돼 있습니다.
  → 교수님이 «디텍션 돌려서라도 세라»고 하셨지만, **디텍션 없이 세는 것이 표준 논문 방식**입니다.
- 이들은 연결요소로 세기 위해 **«경계선» 클래스를 일부러 추가**했습니다.
  즉 **그냥 연결요소로 세면 붙은 알이 하나로 합쳐진다**는 것을 논문이 전제하고 있습니다.
  우리는 라벨에 경계선 클래스가 없으니 그 역할을 **워터셰드**가 대신한 것입니다.
- 이들도 Mask R-CNN(디텍션 계열)과 **비교 실험**을 해서 자기 방법을 방어했습니다.
  우리는 **사과 정답과 비교**해서 방어했습니다. 논리 구조가 같습니다.

### ③ MinneApple — Häni, Roy, Isler (2020) — 「장당 개체 수 통계」의 근거

| 항목 | 내용 |
|---|---|
| 제목 | MinneApple: A Benchmark Dataset for Apple Detection and Segmentation |
| 저자 | Nicolai Häni, Pravakar Roy, Volkan Isler (Univ. of Minnesota) |
| 출처 | IEEE Robotics and Automation Letters (RA-L), 2020 / arXiv:1909.06441 |
| 서버 사본 | `문서/1909.06441v2.pdf` |

- 우리 «사과» 데이터가 바로 이 데이터셋입니다.
- 초록: "Our dataset contains over 41'0000 annotated object instances in 1000 images."
  → 우리가 인스턴스 ID로 직접 센 값 **40,464개 / 장당 40.4개**와 일치합니다.
  **우리 카운팅이 논문 값으로 검증된 셈**입니다.
- **«붙어 있는 과실 계수»가 별도 과제로 인정돼 있습니다** — 초록:
  "Additionally, we provide data for **patch-based counting of clustered fruits**."
  즉 «열매가 붙어 있어 세기 어렵다»는 것은 우리만의 문제가 아니라 이 분야의 공인된 난제입니다.
- 4쪽 본문에 **장당 인스턴스 수 비교**(MinneApple 41.2 / COCO 7.7 / ImageNet·PASCAL VOC 3 미만)가
  글자로 적혀 있고, Fig.3 이 그 분포 그림입니다. → **우리 «그림 3»이 이 형식을 따른 것**입니다.
- 4쪽 Image Annotation 절: 나무에 달린 과실만 폴리곤으로 라벨했고 **땅에 떨어진 것과 뒤쪽 나무는
  라벨하지 않았다**고 명시 → 우리 그림 캡션의 «땅에 떨어진 과실 미라벨»은 이 문장이 근거입니다.

## 4. 논문/발표에 그대로 쓸 수 있는 문장 (영문 초안)

> Because our annotations are binary masks rather than instance boxes, we do not train an object
> detector to obtain per-image fruit counts. Instead we recover individual fruit instances directly
> from the masks using a distance-transform watershed, following Bargoti and Underwood [1], who
> post-process pixel-wise apple segmentations with watershed to detect and count individual fruits
> and report it as their best-performing detection strategy (F1 = 0.858). Naive connected-component
> labelling merges adjacent fruits into a single component; this is precisely why Zabawa et al. [2]
> introduce an explicit 'edge' class so that neighbouring berries can be separated and counted with
> connected components. On the apple subset, whose masks encode instance identifiers, our
> watershed-based count deviates from the ground truth by only +0.7% (median per-image relative
> error 3.8%; 95.5% of images within ±20%), whereas connected components underestimates the
> ground truth by 18.2%.

참고문헌
- [1] S. Bargoti and J. P. Underwood, "Image Segmentation for Fruit Detection and Yield Estimation
  in Apple Orchards," Journal of Field Robotics, 2017. arXiv:1610.08120.
- [2] L. Zabawa, A. Kicherer, L. Klingbeil, R. Töpfer, H. Kuhlmann, R. Roscher, "Counting of Grapevine
  Berries in Images via Semantic Segmentation using Convolutional Neural Networks,"
  arXiv:2004.14010, 2020.
- [3] N. Häni, P. Roy, V. Isler, "MinneApple: A Benchmark Dataset for Apple Detection and
  Segmentation," IEEE RA-L, 2020. arXiv:1909.06441.
