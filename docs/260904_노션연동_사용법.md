## 결론 먼저

**서버는 노션에 직접 접속하지 못합니다. 그리고 앞으로도 안 할 겁니다.**
대신 이렇게 나눕니다.

- 노션 **읽기·백업** = **로컬 클로드** 담당
- 노션에 **쓰기** = 서버가 만든 md 를 사람이 **붙여넣기**
- md 사본 **보관·검색** = **서버** (`platform/01_references/notion/`)

## 왜 서버 토큰 방식을 폐기했나

2026-09-04 로컬 크롬으로 직접 확인했습니다.

곽동신 계정은 교수님 워크스페이스(Hongryul Ahn의 Notion)의 **게스트**입니다.
노션 개발자 도구 페이지는 열리지만,

- **신규 연결** → "이 워크스페이스에서 연결을 생성할 권한이 없습니다" (빨간 글씨, 생성 버튼 비활성)
- **개인 액세스 토큰** → "이 워크스페이스에서 토큰을 생성할 권한이 없습니다" (동일)
- 워크스페이스 선택 **드롭다운 자체가 없음** (게스트는 단일 워크스페이스)

즉 서버용 토큰을 **발급할 방법이 없습니다.**

### 교수님께 권한 변경을 요청하지 않는 이유
- 얻는 게 없습니다. 로컬 클로드로 이미 되고 있습니다.
- 서버는 **팀 공용 계정**이라 워크스페이스 토큰을 거기에 두는 것이 적절하지 않습니다.

**이 결정은 확정입니다. 다시 제안하지 않습니다.**

### 로컬은 왜 되나
로컬 클로드의 노션 커넥터는 **워크스페이스 토큰이 아니라 사용자 계정 OAuth** 입니다.
곽동신 님 본인 계정으로 로그인해서 접근하는 방식이라 **게스트여도 정상 동작**합니다.
실제로 2026-09-02 에 블루베리 페이지 6개를 읽어 외장하드 노션백업 폴더에 md 로 저장했습니다.

## A. 노션에 올릴 내용이 필요할 때 (서버 → 노션)

서버 클로드에게 **"노션에 올릴 거 정리해줘"** 라고 하면
`문서/YYMMDD_노션붙여넣기_<주제>.md` 를 만들어 줍니다.

1. VS Code 에서 그 파일을 엽니다
2. 전체 선택 후 복사 (`Ctrl+A`, `Ctrl+C`)
3. 노션 페이지에 붙여넣기 (`Ctrl+V`)

노션은 마크다운을 붙여넣으면 제목·불릿·체크박스를 알아서 살려 줍니다.
손으로 다시 쓸 필요가 없습니다.

> 서버가 만드는 파일에는 **표를 넣지 않습니다.** 노션 붙여넣기에서 잘 깨집니다. 불릿으로 씁니다.

## B. 노션 내용을 서버로 가져올 때 (노션 → 서버)

### 1) 로컬 클로드에서 뽑기
로컬 클로드에게 노션 페이지를 읽어 md 로 저장해 달라고 합니다.
지금까지 하시던 방식 그대로입니다. (외장하드 노션백업 폴더)

### 2) zip 으로 묶어 서버에 올리기
받는 곳은 여기입니다.

```
/data/project/2026summer/platform/01_references/notion/
```

⚠️ 폴더 드래그는 금지입니다. 과거에 4번 다 실패했습니다. **반드시 zip 1개**로 올립니다.

### 3) 서버에서 풀기

```bash
cd /data/project/2026summer/kds0206
python3 tools/notion_import.py <zip경로>
```

- `platform/01_references/notion/<YYMMDD>_로컬백업/` 에 풀립니다
- `_INDEX.md` 목차를 자동으로 만듭니다 (파일명, 첫 제목, 크기)
- 윈도우에서 만든 zip 의 **깨진 한글 파일명을 복구**합니다
- **기존 백업은 절대 지우지 않습니다.** 같은 날짜면 `_2`, `_3` 을 붙입니다
- 미리 보려면 `--dry-run`, 날짜를 지정하려면 `--date 260902`

### 4) 서버에서 찾아보기

```bash
ls -la /data/project/2026summer/platform/01_references/notion/
grep -rn "찾을내용" /data/project/2026summer/platform/01_references/notion/
```

서버 클로드에게 **"노션 확인해봐"**, **"팀원들 노션에 뭐 썼는지 봐줘"** 라고 하면
이 미러를 읽어서 요약해 줍니다. **다만 사본이라 실시간이 아닙니다.**
클로드가 답할 때 그 사본의 날짜를 같이 말해 줍니다.
최신 내용이 필요하면 로컬 클로드로 다시 뽑아 올리면 됩니다.
