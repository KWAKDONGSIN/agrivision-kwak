# 이 창을 닫아도 계속 돌아가게 하는 법 (곽동신용)

## 왜 필요한가
지금 세션은 **VS Code 창(SSH)이 끊기면 같이 끝납니다.** 예약해 둔 토요일 Codex 점검도 이 세션 안에만 있습니다.
서버 안에 남는 터미널(tmux)에서 클로드를 켜 두면 노트북을 꺼도 계속 돕니다.

## 딱 세 줄 (VS Code 터미널에서)
```bash
tmux new -s claude
cd /data/project/2026summer/platform/planning
claude --resume
```
- 세 번째 줄에서 «오늘 이 대화» 를 고르면 그대로 이어집니다.
- 이어진 뒤 클로드에게 **"상자 기능 5회 검수 계속하고 토요일 Codex 점검 다시 예약해"** 라고 한 번 말해 주세요.
  (예약은 세션 안에만 사는 것이라 새 세션에서 다시 걸어야 합니다.)
- 그 다음 VS Code 창을 닫아도, 노트북을 꺼도 서버의 tmux 안에서 계속 돕니다.

## 다시 들여다보기
```bash
tmux attach -t claude      # 화면으로 들어가기
# 빠져나올 때는 Ctrl+b 를 누르고 d
tmux ls                    # 지금 떠 있는 tmux 목록
```

## 라벨링 툴은 이미 따로 떠 있습니다
툴 서버(5111)는 nohup 으로 떠 있어서 이 창과 무관하게 계속 돕니다. 껐다 켜려면:
```bash
bash /data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴/app/run.sh restart
```

## 주의
- AI 가 사람 없이 스스로 돌게 만드는 자동 실행 스크립트(cron + headless 클로드)는 클로드 코드 안전장치가 막습니다.
  그래서 «창을 닫아도» 의 정답은 위의 tmux 입니다.
- 토요일 예약은 이 세션이 살아 있어야 뜹니다. tmux 로 옮겨 두면 토요일까지 살아 있습니다.
