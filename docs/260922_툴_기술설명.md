# 라벨링·검수 툴 — 어떤 기술로 어떻게 만들었나

만든 사람: **곽동신** (AI 바이브 코딩 — 교수님 09-15 지시 «라벨링 툴을 바이브 코딩으로 웹사이트처럼 만들어 보세요»).
만든 기간: 2026-09-16 ~ 2026-09-22. 이 문서는 서버의 실제 파일을 읽고 잰 값만 적었다.

## 1. 한눈에

- **무엇**: 네 과일(복숭아·포도·사과·블루베리) 사진의 **마스크(칠한 영역)·상자·열매 번호**를 사람이 보고 고치고, 사진마다 **판정(OK·AI로 교체·문제·제외)**을 내리는 웹사이트.
보안 관련 값·설정 세부는 공개본에서 생략했습니다.
- **크기**: 파이썬 4,085줄 · 자바스크립트 5,267줄 · HTML/CSS 1,168줄 · 시험 코드 10,856줄 · API 주소 36개.
- **쓴 것**: Python 3.11 · Flask 3.1 · Pillow 12 · numpy 2.4 · scipy 1.16. 화면은 라이브러리 없이 순수 자바스크립트와 Canvas.
- **데이터베이스 없음**. 판정은 JSON 파일, 수정한 마스크·번호는 PNG 파일로 저장한다.

## 2. 수정하면 언제 저장되나

| 하는 일 | 서버에 저장되는 때 | 저장 위치 (툴 폴더 기준) |
|---|---|---|
| 판정 1~4 · 확정 | **누르는 즉시** (`POST /api/status`) | `data/<과일>/status.json` |
| 마스크 칠하기·지우기 | **Ctrl+S 를 눌러야** (`POST /api/save`) | `data/<과일>/masks_fixed/<사진>.png` |
| 상자 그리기 | **Ctrl+S 를 눌러야** (`POST /api/boxes`) | `data/<과일>/boxes/<사진>.json` |
| 열매 번호 | **Ctrl+S 를 눌러야** (`POST /api/save_instances`) | `data/<과일>/instances_fixed/<사진>.png` |
| 데이터 정리 탭 «서버에 저장» | 누르면 바로 내보내기 시작 | `exports/` (manifest.csv 포함) |

**답**: 판정은 바로 저장된다. 그림(마스크·상자·번호)은 **Ctrl+S 를 눌러야** 저장된다. 그림을 자동 저장하지 않는 이유는, 붓질 중간 상태가 서버에 계속 쓰이면 «되돌리기»와 «누가 언제 확정했나»가 섞이기 때문이다. 그 대신 저장을 잊는 사고를 막는 장치를 다섯 겹 두었다.

1. 저장 안 한 것이 있으면 파일 이름 옆에 **«*»** 가 뜨고 저장 단추가 노랗게 된다 (`dirtymark.js`).
2. 저장 안 하고 창을 닫거나 다른 사진으로 가면 **경고창**이 뜬다 (`mask.js` beforeunload).
3. **1분마다 브라우저 안(localStorage)에 임시 사본**을 적어 둔다. 브라우저가 죽어도 같은 사진을 다시 열면 «되돌릴까요» 를 묻는다 (`backup.js`).
4. 서버가 안 닿으면 **안 사라지는 붉은 알림**이 뜬다. 조용히 실패하는 일이 없다.
5. 같은 사진을 두 번 동시에 저장하지 못하게 **저장 잠금**을 건다.

원본 사진·마스크 폴더는 **읽기 전용**이다. 사람이 고친 것은 툴의 `data/` 에만 쓴다. 원본은 어느 단추로도 바뀌지 않는다.

## 3. 파일 저장이 안전한 이유

- **임시 파일에 쓰고 이름을 바꾼다** (`os.replace`). 쓰다가 서버가 죽어도 반쪽짜리 파일이 남지 않는다.
- 임시 파일 이름에 **프로세스 번호와 스레드 번호**를 붙인다. 09-18 에 «동시 46요청에서 판정 40건이 사라지는» 버그를 실측으로 찾아 이렇게 고쳤다.
- 같은 사진에는 **자물쇠**(`lock_for`)를 걸어 두 사람이 동시에 쓰지 못하게 한다.
- `status.json` 은 **쓰는 길이 한 곳뿐**이다 (`core/status_store.py`). 판정을 바꾸면 이전 값을 `prev` 에 한 벌 남긴다.
- **사람 확정은 AI 제안을 덮지 않는다.** `confirmed` 칸을 따로 얹는다. 되돌리면 확정만 벗긴다.
- 일괄 작업 전에는 `status.json` 을 `_status_backup_<시각>.json` 으로 복사해 둔다.
- 마스크는 0/255 8비트 PNG, 번호는 uint16 PNG(65,535개까지). 저장 전 크기가 원본과 같은지 검사한다.

## 4. 구조 — 어디에 무엇이 있나

```
260916_라벨링툴/
  app/
    server.py          앱을 만들고 기능 묶음을 붙이기만 한다 (94줄)
보안 관련 값·설정 세부는 공개본에서 생략했습니다.
    domain/            maskio(PNG 형식) · statusfmt(판정 항목의 꼴) · rules(데이터 규칙을 이름 있는 함수로) · dupes(근접 중복)
    api/               주소(라우트) 9묶음: photos · masks · boxes · instances · counts · dupes · export · dashboard · team_review
    static/            index.html + js/ 17개 (keys.js 단축키 정본 34개 · mask · boxes · instances · list · view · mobile · easy …) + css
    run.sh             서버 켜기/끄기/다시 켜기 (nohup · PID 파일 · 보던 데이터 폴더 기억)
  data/<과일>/         사람이 고친 것 (status.json · masks_fixed · instances_fixed …)
  export/              수정판 데이터셋 내보내기 스크립트
  tests/               시험 6묶음 (run_all.sh 한 번에)
  scripts/             watchdog.sh(1분 감시) · ff.py(헤드리스 파이어폭스 조작)
  cycles/              날짜별 개발 사이클 기록 (계획·체크리스트·검수·결정)
```

요청이 흐르는 길: 브라우저(JS) → Flask 라우트(`api/*.py`) → 규칙·형식(`domain/`) → 파일(`data/`). 각 `api/*.py` 는 `register(app, ctx)` 하나만 갖고, 서로 직접 부르지 않는다.

## 5. 기술을 이렇게 고른 이유

| 고른 것 | 대신 고를 수 있던 것 | 왜 이걸로 |
|---|---|---|
| Flask 한 프로세스 | Django · FastAPI · Node | 5~10명 팀. 파일 하나로 켜지고, 서버 어디든 복사하면 돌아간다 |
| 파일(JSON·PNG) 저장 | DB(SQLite·Postgres) | 백업·복사·깃·손으로 열어 보기가 쉽다. 원본 데이터셋도 파일이라 형식이 같다 |
| 순수 JS + Canvas | React·Vue | 빌드 단계가 없다. 파일 고치고 새로고침이면 끝. 팀원 누구나 고칠 수 있다 |
보안 관련 값·설정 세부는 공개본에서 생략했습니다.
| 크론 감시자 | systemd | 사용자 권한만으로 된다. 1분마다 살아 있는지 보고, 죽으면 다시 켠다. 재부팅 때도 켠다 |
| 헤드리스 파이어폭스 시험 | 손으로 눌러 보기 | 진짜 브라우저로 977개 동작을 자동으로 누른다. 화면을 고칠 때마다 다시 돌린다 |

| 묶음 | 무엇을 보나 |

## 8. 팀원이 이 툴을 고치는 법

### 8-1. 서버에서 바로 고치기 (지금 바로 된다)

- 툴 폴더 `/data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴` 은 **lab 그룹이 읽고 쓸 수 있다**. 팀원 계정으로 VS Code Remote 를 열어 그대로 고치면 된다.
- **화면 파일**(`app/static/` 의 html·js·css)을 고쳤으면 **브라우저 새로고침**이면 끝이다. 서버를 다시 켤 필요가 없다.
- **파이썬**(`app/*.py`)을 고쳤으면 서버를 다시 켜야 한다. 서버 프로세스는 곽동신 계정 것이라 팀원이 직접 못 끈다. 대신 이렇게 한다.

```
touch /data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴/app/logs/restart.flag
```

  1분 안에 감시자가 서버를 다시 켠다. 그동안 3초쯤 접속이 끊긴다. 결과는 `app/logs/watchdog.log` 에 적힌다.

- 고치기 **전에** 빠른 시험을 돌린다 (30초). 실서버에서 시험하지 않는다.

```
cd /data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴
bash tests/run_all.sh --no-merged --only=syntax,unit,sim,api
```

- 지킬 것: 원본 데이터셋 폴더는 건드리지 않는다. 고치기 전 파일은 `_backup_YYMMDD_이름` 으로 한 벌 남긴다. 남의 프로세스는 끄지 않는다. 포트 5100·5101·5105 는 교수님 것이다.

### 8-2. 깃허브로 고치기

- 저장소: `github.com/KWAKDONGSIN/agrivision-kwak` (공개). 코드는 `labeltool/` 아래. 사진·비밀값은 없다.
- 팀원이 **push** 하려면 곽동신이 깃허브에서 **Settings → Collaborators → Add people** 로 팀원 계정을 넣어야 한다. 서버에서는 할 수 없다. 넣기 전에는 fork 해서 Pull Request 로 보내면 된다.
- 깃허브 사본은 비밀값을 가린 복사본이다. 서버 실파일 위에 그대로 덮어쓰지 않는다. 서버 반영은 8-1 방식으로 한다.
