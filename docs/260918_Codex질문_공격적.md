`split_group` 은 복숭아·포도의 경우 **툴 `duplicates.json` 의 근접 중복 묶음 ∪ 같은 `session`** 으로
만들었습니다(사과·블루베리는 검수판 manifest 의 값을 그대로 씁니다).
