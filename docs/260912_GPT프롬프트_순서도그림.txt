작성: 2026-09-12
용도: 교수님 팁("순서도 이미지는 GPT 가 레이아웃이 낫다, 그린 뒤 클로드에 SVG 로 따 달라 하면 편집 가능")대로 GPT 에 순서도 그림을 시키는 프롬프트. 아래 ===== 사이를 그대로 복사해 GPT 에 붙여넣기. 그림 생성이 되는 모델(GPT-4o 이상, 이미지 생성 켜진 상태)에서.

=====

실험 설계 순서도를 한 장 그림으로 만들어줘. 랩미팅 슬라이드에 넣을 거라 가로형(16:9), 흰 배경, 한글 폰트가 깨지지 않게, 글자는 작아도 읽히게 해줘. 아래 상자 글자와 숫자는 한 글자도 바꾸지 말고 그대로 써. 없는 상자를 추가하지 마.

[레이아웃]
- 맨 위 가운데: 상자 A → 상자 B (아래로)
- 그 아래 왼쪽 큰 영역 = "파일럿 20% (탐색적)" 주황색 점선 테두리. 안에 C1, 파일럿0, V, P, C 상자
- 그 아래 오른쪽 큰 영역 = "본실험 80% (확증적)" 초록색 점선 테두리. 안에 M1, M2~M5, W1, W2 상자
- 맨 아래 가운데: 상자 R
- 상자 색: 완료된 것(C1) 회색, 실행 중(파일럿0) 노란 테두리 굵게, 파일럿 상자 연한 주황, 본실험 상자 연한 초록, 산출(W1·W2·R) 연한 보라

[상자 글자 — 그대로]
A: 144조합 = 헤더 12종 × 백본 12종
   후보 선정에 성능은 쓰지 않음 · 2026-09-08 동결 · 스모크 144/144 PASS

B: 데이터 4종을 한 번만 나눔 (결정 12, seed 3407)
   파일럿 20% (본실험에 재사용 금지) | 본실험 80% = M1·M2·M3·M4·M5
   파일럿 안은 4분할: 회전마다 학습 2 · 검증 1 · 시험 1 → 데이터셋당 4회전 (결정 29)
   블루베리 1,195 = 239 + 956 · 사과 1,001 = 200 + 801 · 복숭아 125 = 25 + 100 · 포도 2,502 = 500 + 2,002

C1: C1 — 48런 완료 (이력)
    대표 2×2 {BackboneUNet, VWFormer} × {ResNet-50, MiT-B2} × 4데이터셋 × 옛 3-fold
    300 epoch 완주 · fast vs standard 조기종료 비교

파일럿0: 파일럿0 — 64런 실행 중
    같은 대표 2×2 × 4데이터셋 × 4회전 (결정 30)
    800 epoch 완주 · 매 epoch 검증·시험 궤적 + 자원 기록
    시험 점수로는 아무것도 고르지 않음

V: validation process 동결
   조기종료 규칙 · 체크포인트 규칙 확정. 이후 바꾸지 않음

P: P 파일럿 선별 — 2,304런
   144조합 × 4데이터셋 × 4회전
   검증 fold 로 체크포인트 선택 → 시험 fold 의 image-macro Dice
   데이터셋별 4회전 평균 → 4데이터셋 동일가중 · 효율은 점수에 안 넣음

C: A ∪ B → C 동결 (결정 15)
   A = 헤더별 1등 백본 12개 · B = 백본별 1등 헤더 12개
   C = A ∪ B, 12 ≤ |C| ≤ 23 · 파일럿 끝나면 잠금

M1: M1 본실험 — 576런
    144조합 전부 · 학습 M2∪M3∪M4∪M5 → 시험 M1
    M1 결과로 C 를 바꾸지 않음 (결정 25)

M2~M5: M2~M5 확증 — 192~368런
    C 만 나머지 4-fold 추가 → C 는 5-fold OOF 완성 · 16 × |C| 런

W1: Full-grid winner
    144조합 공통 M1 1위

W2: Cross-validated winner
    C 의 5-fold OOF 1위 = 실무 최종 권장

R: 보고
   test = 전체 영상 슬라이딩 윈도우 512 / stride 384 / threshold 0.5 · image-macro Dice
   주효과 · 상호작용 · 데이터 조건별 선택 원칙
   통계 = paired 비교 + 다중비교 보정 (Friedman 보조, 블록 = 데이터셋 4)
   효율은 보고만, 선정에 안 씀

[화살표 — 이 순서대로만]
A → B
B → C1, B → 파일럿0
C1 → V, 파일럿0 → V
V → P
P → C
C → M1 (화살표 위에 "144조합 전부")
C → M2~M5 (화살표 위에 "C 만")
M1 → W1
M2~M5 → W2
W1 → R, W2 → R

[맨 아래 한 줄]
런 수: 2,304 + 576 + 192~368 = 3,072~3,248 (C1 48 · 파일럿0 64 포함 3,184~3,360). C0 옛 6런은 별도.

[범례 한 줄]
회색 = 완료(이력) · 노랑 테두리 = 실행 중 · 주황 = 파일럿 · 초록 = 본실험 · 보라 = 산출

그린 뒤에 상자 글자 중 원문과 다른 게 있으면 목록으로 알려줘.

[GPT 가 그림을 준 다음 할 일]
1. 그림을 저장한다.
2. 숫자를 눈으로 대조한다: 144 / 48 / 64 / 2,304 / 576 / 192~368 / 3,072~3,248 / 12 ≤ |C| ≤ 23 / 512 / 384 / 0.5. 하나라도 다르면 "○○ 상자의 숫자가 틀렸다, 원문대로 고쳐줘" 라고 다시 시킨다.
3. 편집 가능한 파일이 필요하면 로컬 클로드에 그림을 첨부하고 "이 그림을 그대로 SVG 로 만들어줘. 글자와 숫자는 첨부한 프롬프트의 상자 글자를 그대로 써" 라고 한다(이 파일을 같이 첨부).
4. 서버 클로드가 만든 SVG(문서/260912_실험설계_순서도_2판.svg)도 있으니 GPT 그림이 마음에 안 들면 그냥 그걸 쓰면 된다.
