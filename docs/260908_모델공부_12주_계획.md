# 12주 모델 공부 계획 — 헤더 하나 + 백본 하나를 한 주에 짝지어

## 왜 이렇게 짰나

- 교수님이 말한 "12개"는 헤더 12종과 백본 12종 둘 다를 가리킨다. 24개를 한 주에 하나씩 하면 24주라 너무 길다. **한 주에 헤더 1 + 백본 1 을 짝지으면 12주에 끝난다.**
- 짝은 **같은 시대·같은 계열**로 묶었다. 그래야 "그 시절엔 인코더도 디코더도 이런 생각으로 만들었구나"가 한 번에 보인다.
- 순서는 **시대순**이다. 뒤 모델은 앞 모델의 문제를 고친 것이라 앞부터 봐야 이해된다. 교수님 planning 문서 §5 의 «기준 → 최신 비교» 쌍 6개가 그대로 순서 안에 들어간다.
- 발표 한 번은 **10분**이면 된다. 아래 「발표 틀」 다섯 칸을 채우면 끝.

## 발표 틀 (매주 같은 다섯 칸)

1. 한 줄 정의 — 이 모델은 무엇을 어떻게 한다.
2. 이전 모델의 무슨 문제를 고쳤나 — 앞 주 모델과 연결.
3. 그림 한 장 — 원 논문 Figure 1 또는 2 를 그대로 가져와 설명.
4. 우리 grid 에서의 자리 — 무슨 계열의 대표인가, 교수님 §5 의 어느 «기준→최신» 쌍에 속하나.
5. 우리 데이터(작다·많다·겹친다)에 왜 유리하거나 불리할 것 같나 — 농업 선례가 있으면 한 줄.

## 12주 순서

### 1주 — FCN (2015, CVPR) + ResNet-50 (2016, CVPR)
- 헤더: 픽셀마다 분류하는 최초의 end-to-end 망. "dense prediction"이 무슨 뜻인지 여기서 배운다.
- 백본: residual(지름길) 연결. 모든 뒤 모델의 기준점(anchor).
- 왜 첫 주: 이 둘이 없으면 나머지 22개를 설명할 수 없다.

### 2주 — U-Net decoder (2015, MICCAI) + HRNetV2-W32 (2019, CVPR / TPAMI 2020)
- 헤더: 대칭 복원 + skip connection. 우리는 독립망이 아니라 4단계 특징을 받는 BackboneUNet 으로 쓴다(결정 22).
- 백본: 해상도를 줄이지 않고 병렬로 유지. "고해상도 유지"라는 다른 접근.
- 짝 이유: 둘 다 "작은 것을 놓치지 않으려면 해상도를 살려라"는 생각.

### 3주 — PSPNet head (2017, CVPR) + ConvNeXt-T (2022, CVPR)
- 헤더: pyramid pooling 으로 전역 문맥. 우리 2×2 설계의 PPM 축.
- 백본: ResNet 을 Transformer 시대 기법으로 현대화한 CNN. ResNet-50 → ConvNeXt 가 교수님 «고전 CNN 대비 현대 CNN» 쌍.
- 짝 이유: "CNN 으로도 더 넓게 볼 수 있다"는 두 가지 답.

### 4주 — DeepLabV3+ head (2018, ECCV) + MSCAN-B (2022, NeurIPS, SegNeXt 인코더)
- 헤더: atrous(구멍 뚫린) 합성곱으로 수용 영역 확장 + 얕은 특징 결합.
- 백본: 여러 크기의 depthwise conv 로 attention 을 흉내내는 convolutional attention.
- 짝 이유: 둘 다 "attention 없이 합성곱만으로 넓게 보기".

### 5주 — Semantic FPN (2019, CVPR, Panoptic FPN) + Swin-T (2021, ICCV)
- 헤더: top-down 피라미드 융합. 우리 2×2 설계의 FPN 축.
- 백본: 창(window) 안에서만 attention 하고 창을 밀어(shift) 연결. Transformer 백본의 표준.
- 짝 이유: 이 주부터 Transformer 가 등장. FPN 은 Swin 논문의 기본 디코더이기도 하다.

### 6주 — UPerNet (2018, ECCV) + MiT-B2 (2021, NeurIPS, SegFormer 인코더)
- 헤더: PPM + FPN. 3주·5주의 두 축을 합친 것. 2×2 설계의 네 번째 칸.
- 백본: 겹치는 패치 + 축소 attention. 분할 전용으로 설계된 Transformer.
- 짝 이유: Transformer 시대의 "표준 디코더 + 표준 인코더".

### 7주 — AllMLPNet (2021, NeurIPS, SegFormer 디코더) + UniFormer-S† (2022 ICLR, 저널판 TPAMI 2023)
- 헤더: 합성곱 없이 MLP 만으로 4단계 특징을 섞는다. 우리는 MiT 전용 클래스가 아니라 떼어낸 AllMLPNet 을 쓴다.
- 백본: 얕은 층은 합성곱, 깊은 층은 attention. CNN–Transformer 하이브리드 대표. 0908 에 S†(head_dim 64) 로 교체됨.
- 짝 이유: "가벼운 디코더 + 섞은 인코더" — 인코더 의존이 큰 디코더를 하이브리드에 붙이면 어떻게 되나.

### 8주 — OCRNet (2020, ECCV) + InternImage-T (2023, CVPR)
- 헤더: 객체 영역(object region)별 표현을 만들어 픽셀과 attention. attention 계열 디코더의 유일 생존자.
- 백본: 변형 가능한(deformable) 합성곱 DCNv3. ConvNeXt·MSCAN → InternImage 가 교수님 «고정 sampling 대비 deformable» 쌍.
- 짝 이유: 둘 다 "어디를 볼지를 데이터가 정하게" 하는 생각.

### 9주 — FaPN (2021, ICCV) + TransNeXt-Tiny (2024, CVPR)
- 헤더: 특징 정렬(alignment)을 deformable 로 보정한 FPN. 계보 SFNet → AlignSeg → FaPN.
- 백본: 사람 시각처럼 중심은 세밀하게, 주변은 뭉뚱그려 보는 aggregated attention. Swin·MiT → TransNeXt 가 교수님 «최신 attention 추가 효과» 쌍.
- 짝 이유: 8주의 deformable 생각이 디코더(FaPN)와 인코더(TransNeXt) 양쪽으로 발전.

### 10주 — HamNet / LightHam (2021, ICLR) + MogaNet-S (2024, ICLR)
- 헤더: 행렬분해(NMF)로 전역 문맥. attention 이 아닌 다른 전역 문맥 방식의 대표.
- 백본: 여러 차수의 게이트 합성곱. 2024년의 현대 CNN. ResNet-50 → ConvNeXt·MogaNet 쌍.
- 짝 이유: 둘 다 "attention 없이 전역을 보는 다른 수학".

### 11주 — VWFormer (2024, ICLR) + VMamba-T (2024, NeurIPS)
- 헤더: 크기가 다른 창(varying window)으로 문맥. C1 대표 2×2 의 헤더(결정 26). FPN·UPerNet → VWFormer 쌍.
- 백본: attention 을 상태공간모델(SSM) 스캔으로 대체. Swin·MiT → VMamba 쌍. 0908 에 v2 s1l8 로 동결.
- 짝 이유: 2024년의 "attention 을 더 싸게 또는 아예 다른 것으로".

### 12주 — U-MixFormer (2025, WACV) + vHeat-T (2025)
- 헤더: 디코더 단계마다 cross-attention 으로 섞는 최신 디코더. U-Net → U-MixFormer 쌍.
- 백본: 열전도 방정식(PDE)을 연산자로 쓰는 백본. Swin·MiT → vHeat 쌍. 서지·게재처는 동결 전 검증 대기.
- 짝 이유: 가장 최신 둘. 앞 11주를 알아야 "왜 이게 새로운가"를 말할 수 있다.

## 누가 무엇을

- 팀원 4명이면 한 주에 한 사람이 헤더·백본 한 쌍을 맡으면 된다. 4주에 한 번 차례가 온다.
- 순서를 바꿔도 되지만 **1주(FCN+ResNet)와 5주(FPN+Swin)는 앞에** 두는 것이 좋다. 나머지의 기준점이다.

## 교수님이 "왜 다르다"고 한 mechanism 한 줄 (planning/260905_02 §4·§5·§8)

- 헤더 계열: CNN·pooling 7(FCN, U-Net, FPN, PSPNet, DeepLabV3+, UPerNet, FaPN) + attention 3(OCRNet, U-MixFormer, VWFormer) + MLP 1(AllMLPNet) + 행렬분해 1(HamNet)
- 백본 mechanism: residual bottleneck / modernized large-kernel CNN / 병렬 고해상도 표현 / shifted-window attention / overlapping patch + spatial-reduction attention / shallow conv + deep attention / 2D selective state-space scan / multi-scale large-kernel conv attention / deformable conv DCNv3 / foveal-aggregated attention / multi-order gated aggregation / heat-conduction operator
- 발표 4번 칸("우리 grid에서의 자리")은 이 한 줄을 풀어서 말하면 된다.
