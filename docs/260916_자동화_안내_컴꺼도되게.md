- 지금 돌아가는 클로드 세션은 **서버 위에서** 돌지만, VS Code 창을 닫으면(=SSH 끊김) 세션도 같이 끝납니다.

보안 관련 값·설정 세부는 공개본에서 생략했습니다.

## 4. 깃허브 올리기 — 곽동신이 직접 치는 명령 (2026-09-16 23:50 추가)
클로드 코드의 안전장치가 «공개 저장소 만들기(git init·commit·push)» 를 AI 가 하는 걸 막아서, 마지막 세 줄은 사람이 칩니다. 조립 스크립트(`make_repo.sh`)가 관리 폴더를 비운 뒤 다시 복사하고 논문 초안·회의록·민감도 보고서를 제외하며 서버 주소·실명·모델명을 치환합니다. **아래 순서대로(조립 → grep) 실행해야** 검사가 유효합니다. grep 에 한 줄이라도 나오면 push 하지 말고 클로드에게 보여 주세요.
```bash
cd /data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴
PY=/home/kds0206/.conda/envs/kwak/bin/python
SITE_BUILD_DATE=2026-09-16 $PY site/build_site.py && $PY site/check_links.py && bash site/make_repo.sh
grep -rln "223.195\|/data/project\|/home/kds0206\|랩미팅\|딥시크\|심사자" ~/repos/fruit-seg-labeltool   # 아무것도 안 나와야 정상
cd ~/repos/fruit-seg-labeltool && git init && git config user.name kds0206 && git config user.email clingfim@outlook.com
git add -A && git commit -m "Fruit segmentation review tool + public dashboard (2026-09-16)"
bash /data/project/2026summer/platform/work/kwak_dongsin/260916_라벨링툴/cycles/github_publish.sh   # 2번(github.env) 채운 뒤
```
- 저장소는 **Private 로 먼저** 만들고 사이트를 확인한 뒤 Public 으로 바꾸는 것을 권합니다.
- 첫 push 뒤 GitHub → Actions 탭에서 `pages` 워크플로가 안 돌면 «Run workflow» 를 한 번 눌러 주세요.
