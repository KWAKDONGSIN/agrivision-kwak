## 지금 툴에 빠진 것 — `코드` 항목으로 올린 것 (최대 5)

3. 사람 확정 수와 재학습 준비 상태 표시(G73) — 실제 재학습은 GPU 스크립트라 툴은 «확정 N장, 마지막 내보내기 시각» 과 내보내기 링크만.
4. 512 크롭 박스 표시 토글(G42, G34) — 낮은 우선순위.
5. 사과·포도 규칙 안내 한 줄 도움말(G78) — 교수님 답이 나오기 전에는 «미정» 이라고 적는 형태로만.
