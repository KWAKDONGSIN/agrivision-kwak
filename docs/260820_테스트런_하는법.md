
```bash

# ② 실행 (예: 5번 GPU)
bash /data/project/2026summer/platform/04_experiments/테스트런/run_smoke.sh 5 ahn

# ③ 진행 보기 (화면에 찍어 준 경로를 그대로)

# ④ 끝났는지 — 아래 파일들이 생기면 완료

#    config.yaml          이번 실행에 쓰인 설정 (복사본)
```

## 4. 다른 설정으로 돌려 보고 싶으면

본 실험용 설정 파일이 `04_experiments/학습설정_configs/` 에 전부 있습니다
(이름 규칙 `<데이터>_<head>_<backbone>_bcedice_cv<N>.yaml`).
그중 하나를 `work/<내이름>/` 에 복사해서 `SAVE_DIR` 을 **내 폴더 안의 경로**로 바꾼 뒤:

```bash
cd /data/project/2026summer/kds0206/semantic-segmentation
export PYTHONPATH=$PWD
CUDA_VISIBLE_DEVICES=5 nohup /home/kds0206/.conda/envs/kwak/bin/python tools/train.py \
    --cfg /data/project/2026summer/platform/work/<내이름>/내설정.yaml > /data/project/2026summer/platform/work/<내이름>/log.txt 2>&1 &
```

⛔ `SAVE_DIR` 을 `output/<기존이름>` 그대로 두면 **완성된 체크포인트를 덮어씁니다.** 반드시 바꾸세요.
본 실험(200에폭)은 1폴드에 **수 시간**이 걸리니 먼저 `EPOCHS: 2` 로 스모크 → 줄인 데이터로 파일럿 → 본 실험 순서로(작업규칙.md 5장).

## 5. 안 될 때

| 증상 | 원인 · 해결 |
|---|---|
| `Permission denied ... /home/kds0206/...` | 곽동신 홈의 «들어가기» 권한이 빠진 것. 곽동신이 `chmod g+x /home/kds0206` |
| `CUDA out of memory` | 그 GPU 를 남이 쓰는 중. `nvidia-smi` 로 다른 번호 |
| `ModuleNotFoundError: semseg` | `PYTHONPATH` 누락. 스크립트는 자동 설정하므로 직접 돌릴 때만 해당 |
| 로그가 안 늘어남 | 첫 에폭 앞에 데이터 로딩 10~20초. 그래도 멈춰 있으면 `log.txt` 맨 아래 에러 확인 |
