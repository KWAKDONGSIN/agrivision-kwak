## 2. B — 직접 띄우기 (순서대로)

### ① 서버에 터미널로 들어간다
지금 하던 대로 VS Code Remote 로 접속해서 터미널을 엽니다. (교수님은 MobaXterm 을 쓰셨는데 같은 겁니다)

### ② 띄운다 — 이 한 줄
```bash
cd /data/project/2026summer && nohup /opt/anaconda3/bin/jupyter-lab --no-browser --port 8890 --ip 0.0.0.0 > /data/project/2026summer/kds0206/logs/jupyter_kds0206.out 2>&1 &
```
- `nohup ... &` : 터미널을 닫아도 계속 돈다 (교수님 설명 그대로)
- `--port 8890` : 내 주피터 번호. 남과 겹치면 8891, 8892 로 바꾸면 됨
- `cd /data/project/2026summer` : 주피터 파일 관리자의 «맨 위 폴더». 여기서 `platform/` 과 `kds0206/` 둘 다 보임
- 주피터 프로그램은 서버 공용 아나콘다(`/opt/anaconda3`)에 이미 깔려 있음 (4.2.5). 설치 필요 없음

### ③ 접속 주소를 본다 (= 교수님의 "nohup.out 열어 보기")
```bash
보안 관련 값·설정 세부는 공개본에서 생략했습니다.
```
