# 1. 이번에 결정·확인된 것

## 센터크롭 — 팀 의견은 센터크롭으로 정리됨

- 교수님 정리 — validation은 센터크롭 해도 상관없고, **결국 test에서 센터크롭이냐 슬라이딩 윈도우냐가 결정 지점**
- 팀원 답변 — 찾아본 결과 센터크롭이 맞다고 판단, **근거까지 이미 정리해 넣어둠**
- 최종 확정은 교수님이 서버 클로드로 검토한 뒤

## 블루베리 폴드 수 — 6폴드 → 5폴드로 통일

- 지금 블루베리만 6폴드로 되어 있는데 **5폴드로 바꿔서 다른 데이터셋과 맞추기로 함**
- 교수님 질문 "5폴드 실험으로 충분한가?"에 대한 팀 답변 —
  Friedman 검정 기준으로 5폴드 × 데이터셋 4개 = **결과 20개**가 나와서 유의한 결과를 뽑기에 충분
- (이건 지난주 내가 확인한 Demšar 2006 rule of thumb N>10과 일치하는 답)

## 진행 방식 확정

- 센터크롭 + CV 폴드 수 통일 + Friedman 사후검증으로 진행
- 헤더·백본 선정 근거는 민호가 GPT로 정리해 둔 것이 있고 **MD 파일로 복사 가능** → 서버에 올리기로

# 3. 교수님이 알려주신 것 (기술 설명)

## 리눅스 권한 (chmod)

- `rwx` 3글자 × 3묶음 = 소유자 / 그룹(랩) / 기타
- r=읽기, w=쓰기, x=실행(폴더는 "들어갈 수 있음")
- 읽기 전용으로 만들려면 w 권한을 빼면 됨. **방법은 AI한테 물어보면 됨**
- 팀 전원이 같은 랩 그룹에 속해 있음

## 주피터랩 백그라운드 실행

- 터미널에서 `nohup jupyter lab` 식으로 실행하면 터미널을 꺼도 계속 돌아감
- nohup의 출력 텍스트를 열면 접속 주소가 나옴 → 브라우저로 접속
- 주피터 안에서 터미널 열어 클로드 실행 가능, 핸드폰으로도 이어서 대화 가능
