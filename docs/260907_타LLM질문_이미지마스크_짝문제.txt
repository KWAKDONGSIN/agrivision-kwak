semantic segmentation 학습 데이터셋의 파일 형식과 이미지-마스크 짝 찾기에 관한 질문입니다. 아래 상황을 읽고 마지막 질문에 답해 주세요.

[상황]
1. 원본 데이터셋은 이미지가 bmp, 마스크가 png였습니다. 예: images/1111.bmp 와 masks/1111.png
2. 4개 과일 데이터셋의 총 화소 수를 맞추려고 리사이즈한 사본을 만들면서 이미지도 png로 저장했습니다. 그래서 사본에서는 images/1111.png 와 masks/1111.png 처럼 이미지와 마스크가 둘 다 png입니다.
3. 원본 중 리사이즈가 필요 없던 사진은 bmp와 png를 픽셀 단위로 비교했을 때 완전히 동일했습니다.
4. 폴더 구조는 다음과 같습니다.
   dataset/train/images/*.png
   dataset/train/masks/*.png
   (val, test도 같은 구조)
5. 학습 코드가 이미지와 마스크 짝을 찾는 부분은 다음과 같습니다 (PyTorch Dataset).

    self.img_dir = self.root / split / "images"
    self.mask_dir = self.root / split / "masks"
    allowed = {".png", ".jpg", ".jpeg"}
    self.files = sorted(
        path for path in self.img_dir.iterdir()
        if path.is_file() and path.suffix.lower() in allowed
    )
    missing = [
        path.name for path in self.files
        if not (self.mask_dir / f"{path.stem}.png").is_file()
    ]
    if missing:
        raise RuntimeError(f"Missing masks; first example: {missing[0]}")

    def __getitem__(self, index):
        image_path = self.files[index]
        mask_path = self.mask_dir / f"{image_path.stem}.png"
        image = Image.open(image_path).convert("RGB")
        mask = Image.open(mask_path).convert("L")
        mask = (mask > 0)
