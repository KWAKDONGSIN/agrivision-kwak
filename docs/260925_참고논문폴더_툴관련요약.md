# 03_참고논문_리뷰 폴더 훑기 (M01) — 라벨링 도구·인스턴스 분할·SAM 관련만

폴더: `kds0206/연구실 블루베리/03_참고논문_리뷰/` (PDF 20개 + pptx 3개). 제목·본문 검색(SAM, Segment Anything, 라벨링 도구, 주석, 인스턴스)으로 훑었다. pptx 는 열지 않았다(해바라기 논문 그림 정리라 툴과 무관해 보임).

## 한 줄 결론
폴더 안에 SAM 이나 라벨링 도구를 직접 다루는 자료는 없다. 툴과 이어 쓸 수 있는 건 아래 3편이다.

## 1. 라벨링선택 FewShot 세포분할 논문 (`260713_쉬운정리_라벨링선택_FewShot세포분할논문.pdf`, arXiv:2211.10244)
- 내용. 정답을 달 사진 예산이 적을 때 무작위로 고르지 말고 AI 가 헷갈려 하는 사진을 먼저 고른다. 사진을 돌리고 밝기를 바꿔 여러 번 예측시켜 답이 오락가락하면 «헷갈림».
- 결과. 5종 세포 사진에서 무작위·엔트로피·MC dropout 보다 같은 예산으로 성적이 좋았다.
- 툴에 주는 것. 사진 목록을 «불확실한 순서» 로 정렬하는 기능의 근거다. 이미 리서치 문서(`260925_라벨링툴_리서치.md`)의 2위 후보와 같은 아이디어라 새 코드 항목은 만들지 않았다.
- 주의. 현미경 흑백 사진 기준이라 야외 컬러 열매에서 통하는지는 직접 확인해야 한다(문서 스스로 그렇게 적음).

## 2. 사과 논문 MinneApple 종합정리 (`260722_사과논문_MinneApple_종합정리.pdf`)
- 내용. 약 1,000장·사과 41,000+ 개, 사과마다 폴리곤 인스턴스 마스크. 사진당 평균 41.2개(최대 120), 평균 40×40px(이미지의 0.17%).
- 툴과의 연결. 우리 블루베리(사진당 평균 43개)와 밀도가 같다. 작고 빽빽한 열매를 하나씩 칠하는 작업이라는 점에서 그림판의 «열매 하나 = 인스턴스 하나» 방식이 맞는 방향이다.
- 시사점. 작은 객체(32² px 미만)에서 모든 모델이 크게 떨어진다. 툴에서 작은 열매를 확대해 칠하기 쉬워야 한다는 근거다(기존 확대·이동 기능 유지).
- 폴더에는 마스크를 어떻게 만들었는지(도구·시간)에 대한 기록이 없다.

## 3. Lin2025 나뭇가지 분할 논문해설 (`260710_Lin2025_나뭇가지분할_논문해설.pdf`)
- 내용. 가는 구조는 IoU·Dice 만으로 못 고른다. 객체 단위 P/R/F1, 개수 MAE/RMSE, Boundary-F1 같은 지표를 함께 쓰자는 논문이고, 우리 25개 예측 마스크로 재학습 없이 계산할 수 있다는 정리가 있다.
- 툴과의 연결. 객체 단위 지표와 개수 지표는 «열매 하나하나가 분리된 인스턴스 라벨» 이 있어야 계산된다. 즉 그림판이 인스턴스를 정확히 나눠 저장하는 것이 논문 지표의 전제다. 겹친 열매의 경계 품질이 Boundary-F1 에 그대로 반영된다.

## 그 밖에 확인한 것
- 해바라기 논문 원문(`260713_s11119-026-10362-5.pdf`)은 ArcGIS Pro 로 손으로 다각형을 그려 마스크로 바꿨다고 적고, 한계로 «경계가 애매한 라벨링» 과 «반자동·불확실성 인지 라벨링을 탐색할 만하다» 를 든다. 우리 ✨ 도우미(SAM)와 초벌 검수 방식을 뒷받침하는 문장이다.
- 폐병변 비교 논문, DPT 조사서, 손실함수 논문, 해바라기 해설 자료들은 라벨링 도구·SAM·인스턴스 분할과 무관해 건너뛰었다.
